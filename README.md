# template-Ai｜門禁卡 AI 智慧自動排版

狀態：**需求訪談已收斂（52 題）；技術研究初稿；尚未開始程式開發。**

## 目標
Windows GUI：從多份 Adobe Illustrator .ai 歷史門禁卡作品學習排版規則，歸納少量可解釋、可審核、可重用模板，依輸入資訊與指定尺寸完成排版、驗證及 PDF/PNG/JPG 輸出。
