## 1. 產品定位與目前完成度

產品是 Windows 本機「矩形區域內的自動排版與模板 AI」桌面軟體。每件作品以矩形邊界、寬高、座標系及內容物件表達；名片、門禁卡皆為同一核心的應用名稱，名稱問題已結案。使用者以歷史 .ai 等來源建立可信訓練資料，學習可解釋規則，整理尺寸／人物容量分類的模板，輸入人物與公司資料後自動匹配、排版及輸出 PDF、PNG、JPG。客戶、人物、公司、尺寸獨立 Logo 庫與重訂能力繼續適用。歷史異形／裁切資訊可保留為矩形區域內的附加遮罩或限制，不用商品名稱建立另一套引擎。

匯入以「與可信原稿參考視覺無可辨識差異，且可形成有效訓練資料」為完成標準。Inkscape 為正式納入的解套路徑；完整 Illustrator 私有結構或原生可編輯性不再是所有訓練來源的必過門檻。實體印刷分析安排在軟體功能完善後，前期仍驗證內容完整、幾何、來源視覺與數位輸出一致性。

全倉庫目前都是 Markdown：需求基準、GUI 決策、研究候選、驗收計畫與交接規範。沒有應用程式、資料庫建置程式、模型、測試程式或可執行成品。本次無法給出實作完成百分比；能確認的是規格已有大量核准，產品仍為 NOT_IMPLEMENTED / NOT_VERIFIED。

UI 決策主題共 67 項：UI-001～059、UI-060A、UI-061～067；其中 UI-066 主要是去重及未決報告登記，UI-067 是需求治理，不能把它們算成 67 個彼此獨立的成品功能。UI-052 另有重大錯誤重審追加核准，UI-056 另有後期補樣計畫。完整主題索引見 [功能追蹤表](UI_FEATURE_INVENTORY.csv)。

## 4. 建議架構與技術研究順序

這是建議，不是已核准的技術選型。

- Windows GUI：優先評估 Python＋PySide6/Qt，盤點既有專案可重用元件及授權。既有專案不在本倉庫，不能宣稱 peopleCapacity、Hungarian assignment 或特製排版已具可重用程式碼。
- AI 匯入：優先研究 Inkscape 匯入／轉 SVG／渲染，加上 PDF 相容與影像／輪廓標記路徑。以合法原檔、可信參考圖、視覺差異及有效訓練結果驗證；Inkscape 不是所有 .ai 的通用解析保證。遇不支援／缺字型／效果差異先找替代轉換或參考來源，不能帶差異宣稱完成。Windows Illustrator 原生腳本保留為能增加證據或處理例外的可選路徑，不再要求每個來源都依賴 Illustrator 安裝。
- PDF 備援／渲染：評估 pypdfium2/PDFium；PyMuPDF 需另外查 AGPL／商業授權適用性，不直接變正式依賴。OCR 不能取代原生字型量測。
- 持久資料：評估 SQLite；重用 UI-043 的 customers、people、contact_methods、companies、person_company_links、card_sizes、styles、style_versions、customer_card_styles、content_blobs、source_files、artworks、training_checkpoints、review_events。視需要最小延伸 Logo／模板／規則／樣本／版本與別名，不建平行資料庫。
- 計算核心：以矩形尺寸、座標及內容物件為共同模型；解析、字型量測、語意配對、幾何、學習、數位輸出驗證與檔案寫入保持明確介面，UI 呼叫共同核心。原生／衍生來源、候選、已核准資料、正式發布和短期恢復各有生命週期。實體印刷分析採後期獨立工作包。
- 資源控制：同一受限工作執行架構，區分長期訓練、當次排版及輸出狀態；需要隔離／逾時的工作評估子程序，前景 GUI 不執行重型計算。
- AI 路線：先比較確定性規則、幾何／語意特徵、相似度／聚類及受約束求解；實測需要時選模型。CPU 支援核心流程；RTX 5050 用於可選加速，實際 GPU 相容、VRAM 與模型預算另量測。所有推論附來源／版本，硬條件由可重現驗證核實。
- 安全與授權：前期預留資料存取權限介面，先用合成／合法去識別資料；備份加密、日誌最小揭露及資產使用權從資料設計開始。完整 UI-048 最後接入。

| P3 字型、幾何與單一完整製作鏈 | 實際字型量測、固定字級排版；基本模板草稿／版本、Logo 同尺寸核准／等比放入；人物公司輸入、無損配對；單尺寸 PDF/PNG/JPG 與非正式預覽 | 先用少量明確樣本／人工核准模板驗證排版與輸出核心；Gate 4/5 的相關子集。這是技術閉環，不代表自動學習已完成 |
| P4 資產庫與可解釋學習 | 完整模板庫、配額與去重；尺寸獨立 Logo 庫／變體審核；字型替代工作流；雜訊規則；可信樣本准入、資料集 Manifest、規則與模板候選、發布／回滾、新尺寸預測 | Gate 2/3；同尺寸與新尺寸例外有測試；訓練／保留測試無同源洩漏；不低品質湊數、推論不自動發布 |
| P5 自動排版與多候選多尺寸 | 矩形尺寸匹配與特製排版；硬性檢查後排序、理由與風險；多尺寸預覽／部分正式數位輸出；進度、恢復、人工保護、局部重算與受控同步 | Gate 4 及修訂後 Gate 5 的數位部分；舊計算不可覆寫新修改；各尺寸獨立驗證；無解與未知分開，實體印刷分析留 P10 |
| P6 客戶重訂與資料運維 | 合成資料建檔、客戶／尺寸／版型版本關聯；搜尋、沿用確切版本、逐欄回寫與競爭保護、合併拆分；備份加密／完整性／試還原、移轉、來源重連及監看 | P1 關聯與 P3～P5 核心可用；同名／同雜湊不自動合併，別名前導 0 保留；換機還原後數位輸出仍須重驗 |
| P7 品質中心與核心整合 | 完整審核覆蓋與重大跨批次重審；分類指標／版本比較／根因修復／污染追溯／安全回退；UI-056 C；導航、右側面板、快捷鍵與批次回復整合；低配限流與故障演練 | Gate 6 的核心閉環及獨立複核；持久性、低配啟動、中文輸入法、晚到結果、重試冪等、安全輸出均有證據；測試底座已從 P1 開始，不等到此時才做測試 |
| P8 最後功能：正式權限與個資安全 | 完成 UI-048 登入／單人安全模式／能力權限、遮罩解除、閒置鎖定、資料層存取、敏感匯出與備份還原授權、稽核；驗證開發測試模式無法旁路正式環境 | 核心功能、整合和主要除錯已完成；正式真資料處理及可分發版本前必過安全 Gate。不得保留萬用密碼或隱藏管理員後門 |
| P9 軟體驗收與交付 | 安裝／更新／備份／診斷／復原說明；鎖定來源與依賴、授權、產物雜湊；乾淨 Windows 端到端／數位輸出／視覺驗收，兩類參考機與 CPU／GPU 路徑測試 | 所有本期功能有證據，關鍵 FAIL 未放行；標明匯入支援範圍、已測硬體及未測限制。完成軟體驗收不宣稱已取得實體印刷品質驗證 |
| P10 軟體完善後的印刷分析 | 依實際用途分析印刷樣張、設備／材料、色彩流程、有效解析度、線條／小字、出血與裁切及印製相容性 | 軟體核心、整合及安全功能已完善；建立獨立可重現印刷標準，再決定需要的印刷設定或驗證擴充 |

P1～P3 是核心技術主路徑。P4／P6 可在共同資料模型穩定後安排獨立工作包，但品質測試、版本一致性與低配限制需隨階段驗證。P8 必須維持最後功能實作位置；P9 是驗收與交付，不新增功能。任何較早階段展示只代表其範圍完成。

建議交付里程碑：

- M1：P0～P3，少量真實匿名作品「解析→人工核准模板→輸入→驗證→輸出」可查證；尚不是完整產品。
- M2：P4～P7，所有本期核心功能以合成／匿名資料完成整合，包含自動學習、重訂和恢復；尚未正式處理真實個資。
- M3：P8～P9，最終權限／資料保護與軟體完整驗收通過，形成軟體交付。
- M4：軟體完善後進入 P10，另做實體印刷分析與必要的印製驗證。

## 6. 最重要的驗收案例

1. Inkscape 等適用匯入路徑與可信原稿參考，在相同範圍／比例／渲染條件下視覺無可辨識差異；作品、欄位及完整 Logo 可被標記並供訓練。原生文字、衍生輪廓、點陣／OCR 與未知資訊如實分類，原生可編輯性缺失本身不使訓練匯入失敗。
2. 同 .ai 多作品／多尺寸／跨畫板不漏件，姓名電話不跨人物，完整 Logo 不被拆成普通公司文字。
3. A001.ai 與 B002.ai 位元相同只分析一次，但兩個來源與不同客戶關係完整保留；同名不同內容不能復用舊分析。
4. 長姓名或多筆聯絡資料下，字級保持定案值；受限水平調整仍無合法解就阻擋，不截字、不偷縮字級。
5. A 尺寸有 Logo，B 尺寸沒有：B 不借 A 的 Logo；A 可經確認正式輸出，B 只可匯出標記占位的非正式預覽。
6. 實際 PDF／PNG／JPG 的內容、字型、顏色、透明背景、比例與細節作數位視覺比對，PDF 適用時保留向量；實體樣張與印刷條件移至 P10。檔案產生成功不等於視覺一致或實體印刷已驗證。
7. 人工移框後舊 AI 計算才返回、跨尺寸套用、Undo、關機恢復皆不覆寫新版；過期 PASS 不能正式放行。
8. 批次輸出或修正部分成功，磁碟滿／檔案鎖定／當機／重試不改成功檔、不重複位移、不把半成品當正式成品。
9. 漏審或來源不可解析不被移出分母；重大共同錯誤能追查歷史已結案批次、暫停信任並受控再審。
10. 訓練、調參、保留測試防同源洩漏；錯誤樣本撤銷後不得宣稱模型已自動忘記該資料。
11. 客戶主檔回寫／合併／拆分遇版本競爭不覆蓋新值；備份以隔離還原及關聯核對驗證可用。
12. UI-048 真正限制資料存取與匯出，遮罩不是只隱藏畫面；正式模式無開發旁路。

效能參考範圍：上限為 16 GB 系統 RAM＋NVIDIA RTX 5050，下限為 ASUS VivoBook；上限 CPU／GPU 形式與 VRAM、下限完整型號／CPU／RAM／GPU 待補，不能以系列名稱直接宣告最低配置。16 GB 是整台電腦 RAM，不是程式可占滿的預算；實測後保留 Windows 與其他程序餘量。CPU 路徑可執行核心流程，GPU 為可選加速。測量冷啟動、匯入／訓練／排版耗時、GUI 回應、程序與整機峰值 RAM、VRAM、佇列和中斷恢復；規劃分批、延遲載入、有界並行及必要時降載。可接受水平壓縮、視覺差異判定、樣本量與成功率門檻仍需研究實測。

## 7. 真正未決與研究風險

### 尚待使用者取捨

- UI-066-R1/R2：是否需要卡片預覽以外的獨立問題報告；如需要，其最小格式、附件、去識別與本機人工交接方式。PDF／HTML／JSON 都只是候選；目前未核准報告功能細節，不應先作為必交付功能。
- X-04 已結案：使用者將產品統一抽象為矩形方框中的自動排版與模板 AI，後續不再訪談名片／門禁卡稱呼問題。

### 技術研究，不應再包裝成重複訪談

- Inkscape 對實際 .ai 的匯入／轉 SVG／渲染支援範圍、缺字型／live effect／剪裁／透明度差異，以及可訓練標記的有效性；不支援的檔案須有例外與替代路徑。原生 Illustrator 提取為可選補充研究。
- 中文 shaping、缺字／字型身分、固定字級與水平尺度、實際匯出和嵌入授權。
- 混合畫板的作品切分、複合 Logo、人物公司語意及客戶來源對映。
- 新尺寸／少樣本泛化與美觀評分；如何在硬性合格候選中比較審美。
- Windows GUI／低配限流、持久化／原子寫入／中斷恢復、備份加密與跨版本移轉。
- 第三方精確版本／授權／可分發性、具體快捷鍵／微調步距。
- 客戶資料修正／刪除／匯出、稽核與短期恢復的實際留存政策仍需落實。
