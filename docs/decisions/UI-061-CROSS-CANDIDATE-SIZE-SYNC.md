## 一、核心設計：共用資料同步、版面獨立

1. **共用語意資料**：在**同一次排版工作階段**修改人物 ROOT 所屬姓名、電話、Email、IG、LINE、公司與聯絡欄位等已確認的來源資料，依**同一來源實體／欄位 ID 與歸屬鏈**傳遞至所有真正引用該資料的候選與實體尺寸。不得以字串相同、欄位位置相似推定為同一人物；不屬於該人物／公司者不可被波及。修改人物與公司隸屬關係可能使配對候選失效，須重新核實歸屬，不可直接複製舊位置。
2. **公司與 Logo 強綁**：公司相關資料變更僅影響該公司的合法映射；Logo 以公司實體和**各實體尺寸專用的已核准資產**分開解析與驗證，不能從 A 尺寸直接挪用 B 尺寸的 Logo 圖或既有合格結論。
3. **候選版面獨立**：文字框座標、大小、文字水平壓縮、對齊、特製欄位及群組關係的人工修改，預設**只作用於目前候選＋目前實體尺寸的作品實例**；不同模板的幾何與物理尺寸不直接複製，也不暗中覆寫人工鎖定內容。
4. **有意跨候選／跨尺寸套用**：如果使用者主動選擇「套用至其他候選／尺寸」，先列出具體目標、可套用的屬性、涉及人物／公司／物件及例外，再給差異預覽、影響範圍和確認。不得以無對應物件、座標比例或欄位名稱推測就強套。無法可靠映射時顯示不相容／待人工處理，**不部分偷偷套用**；可保留成功目標與失敗目標的明確逐項狀態。
5. **局部回復**：使用者可回復某個候選某次版面修改或單一套用動作，而不連帶回退其他已確認的人工變更；對**共用來源內容**的回復則必須明示會影響到哪些引用候選，避免「回復其中一張預覽」悄悄將全部人物來源值改回舊資料。支持預覽差異／取消，保留可追溯的操作版本及作用範圍；若版本已過期或回復依賴不存在，須阻擋或要求明確衝突處理，不聲稱一定可無損還原。

## 二、版本與驗證

- 每次共用資料修改產生新的來源版本；候選及尺寸作品記錄引用的來源／模板 `style_version_id`／Logo／字型／模型與規則／人工編輯版本。沿用 UI-059 的版本柵欄，晚到 AI 結果或 UI-058 暫停／恢復結果不得覆寫新值與人工位置。
- 同步後，依依賴圖只重算必要內容與受影響候選，**但每個受影響的正式輸出尺寸都必須重新通過整張作品硬性驗證與 UI-019、UI-027 印前 Gate**，含人物公司資訊無損映射、容量 `peopleCapacity`、相鄰／全域不重疊、裁切安全區、固定字級與允許的 X 軸壓縮、完整尺寸 Logo、字型及來源證據。
- GUI 狀態須可辨識：**已同步待重驗／不受影響／人工編輯保留／跨候選套用待確認／無法安全套用／驗證失敗／已重新驗證**，並可直接定位差異。任何候選從過期轉為可正式輸出須有當前版本 Gate 證據，不能沿用另一尺寸 PASS。
- UI-060 補充決策 A 的「最佳候選／可展開比較／問題定位」作為展示入口，與 UI-018 原候選列表重用；不另造同步管理中心，避免重複功能。

## 三、具體驗收案例（未執行）

1. 有兩人／兩公司、三候選與二實體尺寸時，僅修改人物甲電話：所有引用**人物甲該欄位 ID**的候選、尺寸反映新電話；人物乙的同名欄位不受影響；每項受影響結果標記待重驗。
2. 在候選 A／尺寸 1 手動移動姓名框：候選 B 與尺寸 2 位置維持原狀；AI 局部重算不得還原 A 的人工位置。
3. 主動跨候選套用對齊設定：GUI 先列出可映射與不可映射物件、各目標實際差異；不得把原始物理座標硬複製至不同尺寸，失敗目標保留舊版本與阻擋理由。
4. 公司 Logo 變更只使引用該公司 Logo 及涉及實體尺寸的候選需要核實；沒有尺寸專用合法 Logo 的目標不能被標記合格。
5. 回復某候選的「移動姓名框」不改動電話來源，也不影響其他候選；若回復電話來源值，先顯示所有真正引用者的影響清單。
6. 兩次修改交錯、排版較早運算晚完成或當機恢復時，版本比對阻止舊數據覆蓋新人工內容；不得把舊印前 PASS 當作新版本 PASS。
7. 僅一個尺寸驗證成功時，可依 UI-027 原核准規則對該合格尺寸進行許可的輸出，不得讓失敗尺寸搭便車。
