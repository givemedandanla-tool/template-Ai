## 1. 產品抽象與名稱結案

使用者原文：「『名片或是門禁卡』這個問題，將其抽象化為一個矩形方框中的自動排版與模板AI即可。」

現行產品定義：矩形區域內的自動排版與模板 AI。共同模型使用矩形寬高、座標、物件、欄位／群組、語意、尺寸及版本；名片與門禁卡作應用名稱，X-04 名稱議題結案。既有客戶、人物、公司、Logo、固定字級、模板及重訂功能繼續適用。歷史異形／裁切資訊可作矩形區域內的附加遮罩或限制，不新增另一套商品排版引擎。

## 2. Inkscape 與匯入訓練完成標準

使用者原文：「Illustrator 檔案解析可以利用inkscape來作為解套方法，總之只要確保視覺上無差別，可訓練就算完成任務。」

Inkscape 正式納入 .ai 匯入／轉 SVG／渲染等解套研究路徑；可搭配 PDF 相容層、輪廓、點陣標記與 OCR。可取得的原生資訊繼續保留，完整 Illustrator 私有結構與原生可編輯性不再是所有訓練來源的必要完成條件。

修訂後匯入驗收需同時滿足：

1. 有可信原稿參考，例如獲授權的原稿渲染／既有可信 PDF 或圖片；參考版本、範圍、尺寸和來源可追溯。
2. 轉換結果在相同範圍、比例與渲染條件下，內容、字形、Logo、線條、遮罩、透明度、相對位置與細節視覺無可辨識差異。
3. 可切分作品、建立欄位／完整 Logo 框、標記人物公司歸屬、量測可取得的幾何，並形成可版本化、可人工修正及可實際供模型／規則學習的有效資料。
4. 必須以真實樣本及實際訓練資料管線證明可用；只有轉換檔存在或能顯示縮圖不能宣稱任務完成。
5. 缺失的原始字型、字級、字寬百分比、效果結構或可編輯性標成未知／估算／衍生，不把 OCR 或輪廓推測冒稱原生事實。
6. 原圖只讀；完整複合 Logo 保留，不以拆字、替換字型或重畫商標換取轉換成功。

視覺驗證可使用配準、差異疊圖、像素／輪廓差異量測及人工局部放大核對。抗鋸齒和色彩渲染差異需要在同條件下判讀；不憑空指定相似度分數門檻，也不將「無可辨識視覺差異」直接等同跨引擎像素逐位元一致。

Inkscape 是否能處理每一類 .ai 仍須實測，尤其無 PDF 相容內容、缺字型和特定效果；不支援時保留例外，尋找其他合法轉換／參考路徑。來源任務只有通過上述視覺與訓練條件才完成。

這次放寬的是訓練匯入的原生結構要求；生成新文字時仍需實際可用字型與定案字級下的量測，既有固定字級與無損排版規則继續有效。

## 3. 印刷分析後移

使用者原文：「印刷可以在軟體完善後再做分析。」

前期／軟體驗收保留：

- 內容完整、語意歸屬、矩形尺寸與幾何、邊界／安全區、固定字級及受限水平適配。
- Logo 完整、比例、來源視覺與數位檔案一致。
- PDF／PNG／JPG 實際可開啟、內容／比例／像素／透明度等正確。
- 正式／非正式預覽分流、撞名與安全寫檔、版本有效性及失敗重試。

軟體完善後的 P10 再分析：

- 印刷設備、材料、色彩流程、實體樣張與印製相容性。
- 依實際用途決定有效解析度、線條／小字可讀性、出血／裁切及其他印製標準。
- 需要時再新增經實測的印刷設定或品質檢查。

原 Gate 5 按數位輸出與實體印刷拆分。原文件含印刷驗證的交付條件依本輪授權調整；不將尚未做實體印刷研究作為前期功能開發阻擋。數位輸出通過不宣稱實體印刷品質已通過。

## 4. 效能參考機與研究計畫

使用者原文：「低配效能可以參考上限記憶體個人電腦16gb記憶體+nvdia rtx 5050,下限則是asus vivobook。」

| 層級 | 已指定參考 | 尚待補齊 |
| --- | --- | --- |
| 上限參考機 | 16 GB 系統 RAM＋NVIDIA RTX 5050 | CPU、桌機／筆電形式、GPU VRAM、驅動與實際可用 RAM |
| 下限參考機 | ASUS VivoBook | 完整型號、CPU、RAM、GPU、系統版本 |

VivoBook 是系列，不推定其一定具備特定 RAM／GPU。這是參考測試範圍，尚不是已實測最低配置或所有該系列電腦的相容保證。16 GB 是整機記憶體參考上限，不代表程式可占用全數；程序預算需扣除作業系統和其他程序餘量。未指定整機 VRAM 上限，不把系統 RAM 當 GPU 記憶體。

建議工程方向：

- 核心功能可走 CPU；RTX 5050 為可選加速，模型／框架相容和加速效果需實測。
- GUI 優先啟動，模型按需載入；分批、索引分頁、有界佇列和並行，資源緊張時降低負載。
- 同一固定匿名樣本集與軟體版本，在兩類機器測量冷啟動、匯入／學習／排版耗時、GUI 回應、程序／整機峰值 RAM、VRAM、磁碟、取消續跑與崩潰恢復。
- 比較不同資料量及 CPU／GPU 路徑，依真正數據決定模型大小、批次數、並行數與可用設定，不先承諾秒數或記憶體門檻。
