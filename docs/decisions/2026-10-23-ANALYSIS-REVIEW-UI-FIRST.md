# 決策：先做最小判讀核對工具，採 B 工作台＋C 引導

日期：2026-10-23。來源：本次使用者逐次核對及明確要求持久化。最後「開始討論實機 UI」取代前一則的「實機 AI」。

## 已確認

1. 軟體按檔案分析／模板產出、模板編輯、輸入調用預覽三部分重新審視；先以最小判讀／標記／修正／保存閉環驗證基礎，再推進學習產出。
2. 同一template-Ai倉庫延續開發，規劃獨立小工具入口／下載；既有分析核心按驗證結果選擇重用或替換，避免分叉重複維護。現階段不新建平行倉庫或提前做網頁手機。
3. 採B原稿中心配置，保留C步驟引導。按鈕有白話文字與一致圖標，按需顯示、清楚下一步。
4. 常用面板只處理肉眼可見資訊與歸屬關係；底層數據照存但預設隱藏，入口「查看全部判讀資料」。重要缺失仍白話提示。
5. 總覽保留原稿、雙向選取定位；依量測對象顯示框／尺寸／間距／切齊／基線／分散／群組／歸屬。量測範圍、未知及推估不可混淆。
6. 觀察包保存足夠來源、文字／字型、幾何與關係供後續學習；單件事實不直接變成交換或容量規則。原稿、人工修訂與後續模型分版本保護。
7. 私有作品、字型、DB、人工資料與模型留本地，正常使用離線。GitHub保存規格、程式、合成示例及去識別證據。
