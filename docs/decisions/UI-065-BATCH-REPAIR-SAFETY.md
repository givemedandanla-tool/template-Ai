# template-Ai｜UI-065 多物件／多候選／多作品批次修正：風險分級、差異預覽與安全回復（正式決策）

- 日期：2026-10-12（Asia/Taipei）
- 核准者：Human Owner
- 正式選擇：**D｜智慧分級批次修正＋安全回復**
- 階段：**GUI 需求規劃與未來驗收條件（已核准）；程式未開發、測試未執行**
- 範圍：在既有工作台，對**已定位、實際有證據**的多個錯誤項目發起一次受控批次修正；同時支援不同候選、物理尺寸或來源 .ai 中彼此獨立的作品。不是全面放行的「一鍵自動改完全部」。

## 一、核准功能

1. **同一問題工作台中的精確選取**：沿用 UI-014／015／040／057 已有問題診斷與 UI-034／035／038／039 的物件定位，提供依問題類型、目前工作／來源、畫板／作品 ID、人物／公司、候選 ID、實體尺寸、警告等級、可處理狀態等條件篩選。每個勾選項必須綁定**確切物件／欄位、來源、版本與適用工作範圍**，不可單靠字串相同就將不同人物的電話或不同公司的 Logo 合併修改。顯示真實的「符合篩選 X 筆／實際選取 Y 筆／可安全處理 Z 筆」，不能把未知／尚未載入的項目計入已完成。
2. **風險分級，但不把 AI 信心當授權**：
   - **低風險且可批次**：來源、歸屬、對象、操作方式與每一筆前置條件均已核實，且不更改受保護資訊。例如符合各自固定字級及允許 X 軸縮放邊界的獨立文字框修正；使用者先選定明確範圍及核對差異後批次套用。
   - **需確認**：可能影響相鄰物件幾何、特殊框位／人工位置、來源版本、已綁定的欄位或需確認套用目標；先顯示精確影響，依風險要求單筆或受控分組確認。
   - **高風險／阻擋**：人物 ROOT／公司歸屬衝突、公司 Logo 完整性與合法來源、跨作品／跨公司誤映射、已人工鎖定或核心受保護物件、已發布模板、印前硬性 Gate 不符；**必須逐筆人工審核或先解除實際阻擋條件**，不可因同類問題很多、AI 信心高或一鍵批次而自動核准。高風險不等於允許忽略硬性 FAIL。
3. **先預檢，再看前後差異，再確認套用**：在執行前列出每個被勾選目標的原值與建議值、文字壓縮比例／固定字級、真實毫米幾何、相鄰與安全區碰撞、人物／公司／Logo 歸屬、所依賴的模板 `style_version_id` 與尺寸。以畫布差異預覽及可展開清單呈現；可排除單筆或整組、取消而不修改內容。預檢若尚未完成則顯示「待驗證」，不得假稱預檢 PASS；來源未知或版本不一致應剔除待處理而非猜測。
4. **批次作用範圍與手動鎖定保護**：逐筆核實可編輯性、群組／共享關聯與合法動作，只能變更確切授權集合。跨候選或不同尺寸的版面修正仍走 UI-061 的目標確認／適用差異比對，不能硬複製另一尺寸的絕對座標、完整 Logo 或印前合格狀態。遵守 UI-013 不依字串長度自動改字級、UI-020／025 不拆分複合 Logo；無法在合法 X 軸範圍內適配者保持阻擋，不自動刪字／改人物歸屬／強行外擴安全區。
5. **有界、可中止的分批處理與逐項結論**：低配置 Windows 上按 UI-051／058 的保守資源限額分批；沿用當次任務實際進度，允許安全取消尚未執行的項目，不可把已完成項冒稱已撤銷。每個目標給出「未開始／正在處理／成功套用待重驗／成功且重驗完成／因前置條件不符跳過／高風險待人工／失敗／版本過期／取消」等互斥且可核對狀態，顯示實際執行總數與成功、失敗、跳過數。**部分成功可以被明確接受並保留有效結果，但不能顯示整批成功，也不能把整批的部分 PASS 轉成作品印前 PASS**。
6. **失敗隔離、可重試而不重複套用**：每筆變更有來源物件 ID、操作 ID、目標版本、寫入結果與必要的重驗憑證，失敗不污染其他已確認目標；再次點選重試時只重新檢查確切仍需要處理、依賴未改變的項目。當已完成或未知是否已完成時，必須先核實目前狀態，**不得盲目再次套用位移、壓縮或批次屬性，導致重複變動**。程式異常或磁碟滿時要顯示「結果待核實／未安全保存」，不得承諾全批永久可恢復。
7. **單筆與整批安全回復**：提供「檢視此批紀錄／回復這一筆／回復本次合法批次」等入口；使用 UI-010／034／064 已有 Undo／Redo 和 UI-059 的版本柵欄、UI-061 的跨候選／尺寸回復範圍。回復前對照變更後是否出現更新的人工修改、共用來源改動、模板／Logo／字型變更與正式版本更新；**僅對仍可證明可逆的項目安全回復**，其餘須明示不可直接回復及人工衝突處理，不能無條件把較新人工編輯覆寫。已執行且有合法結果的項目可逐一保留。
8. **批次修正不等於發布、輸出或學習**：套用操作只影響**該當次允許編輯的草稿／標記／候選**；不自動更新原始 Illustrator `.ai`、UI-010 已發布模板、UI-043 客戶主檔、各尺寸正式 Logo 庫或 UI-055 學習訓練真值。若欲正式改模板或學習規則，仍走 UI-007／008／010／040／041 與必要核准；正式客戶主檔回寫只走 UI-045。
9. **每作品、每候選與每尺寸的重新驗證**：局部計算可按 UI-059 最小依賴重算，但每個受影響作品／候選／尺寸，仍必須按當前來源／版本完成全面適用的語意無損映射、人物容量 `peopleCapacity`、人物／公司／完整 Logo 歸屬、固定字級、允許 X 軸縮放、幾何不重疊、安全區、字型、Logo 尺寸品質與 UI-019／027～030 印前 Gate。其他候選或其他尺寸的 PASS 不能代替本尺寸驗證；未驗證／不合格時不可輸出正式 PDF／AI／PNG／JPG。
10. **低干擾透明 UX**：批次總覽能點擊失敗原因直接跳回既有原稿／候選畫布和右側屬性面板，保留 UI-062 返回位置及 UI-063 釘選工具；高風險需審核而非大量重複警告，低風險在同一次確定範圍後不逐項彈出無意義確認。若 AI 算法結果尚未覆蓋全部來源或被 UI-058 暫停，明說「已檢查的局部問題」，不得宣稱全庫問題已全部修復。

## 二、不得重複／修改既有功能

- UI-033 已有**字型替代風險分級批次審核**：本題僅提供統一的批次選取／執行／回復 GUI 容器，不替代其來源字型品質與授權 Gate。
- UI-036 已有**多物件對齊與等距**：本題不新增另一套幾何對齊演算法，只處理對同類合法目標套用及逐筆驗證的流程。
- UI-039／040 已有**標記框批次確認與雜訊規則**：已核准且符合規則命中的雜訊仍可依 UI-040 自動剔除；不把一次批次修正默默升格為全域永久規則，亦不干預高風險標記逐筆審核。
- UI-057 已有**草稿／未知／無解安全界線**，UI-058 當次工作進度，UI-059 編輯世代與失效，UI-061 跨尺寸同步，UI-064 快捷與 Undo；本題直接沿用，不新增第二套批次引擎、永久歷史庫或影子資料來源。

## 三、未來驗收案例（目前未執行）

| 場景 | 必須結果 |
| --- | --- |
| 30 張名片發現 12 個已核實合法的文字 X 壓縮調整 | 顯示實際 12 筆可選，套用前逐筆有原／新比例、字級不變與全卡影響；只改被明確勾選的項目 |
| 5 個不同候選的電話框待對齊 | 以每候選版型及幾何基準作合法對齊，**不**複製 A 候選座標到 B 候選 |
| 3 個不同尺寸 Logo 疑似錯誤 | 顯示所屬公司、各尺寸資產與來源；待逐筆審核，無合法來源者阻擋，不自動替換成其它公司的 Logo |
| 2 個姓名／公司歸屬不明的框 | 不因其他 18 筆低風險項已完成就自動核准該 2 筆，保留待人工且禁止相關正式輸出 |
| 批次中 8 筆成功、2 筆失敗、1 筆跳過 | 精確顯示數據與原因；不出現「全部修正成功」，後續可僅重新核實失敗／跳過項 |
| 批次套用後有人又手動移動其中一個姓名框 | 整批回復前偵測版本衝突，只對可逆的其它項目執行安全回復，不覆寫新人工移動 |
| 同一批次因當機再次啟動 | 根據每項操作與版本核實狀態，不重複套用位移，也不宣稱未落盤項已完成 |
| 某物理尺寸修復成功但另一尺寸仍有安全區衝突 | 僅合格尺寸依 UI-027 授權可做部分正式輸出，失敗尺寸仍阻擋 |
| 含已鎖定框位或不同人物共享公司 | 沒有精確明確核准不得更改；不自動解鎖、不跨人物配錯資料 |
