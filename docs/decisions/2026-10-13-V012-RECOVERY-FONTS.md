# v0.1.2 多作品恢復與本機字型

授權來源：使用者「繼續推進工作」，以及 `2026-10-13-CONTINUED-DEVELOPMENT.md` 保存的持續開發授權。本輪內化既有 UI-038／058 的作品與恢復需求、UI-032 的程式字型載入需求；不重開訪談，也不將部分實作宣稱完整規格完成。

## 已實作

- 每來源多作品：各自名稱、裁切、毫米、欄位及視覺確認狀態；畫布框選新增作品，原標記先保存；來源與作品切換、正常關閉及重開恢復。
- 標記版次：只在內容改變時建立新快照，界面列最近 100 次；恢復舊版形成新保存版次，舊歷史及發布模板不改寫。過期版次不能覆蓋新標記；完整跨視窗合併仍待續。
- 舊資料：新增 SQLite 資料表，保留既有表與單作品記錄，首次開啟該來源時遷移；未替舊模板補造作品版次來源。
- 新學習模板固定來源作品 ID／標記版次；保存及發布檢查該版次所屬來源，不以檔名或相同雜湊混配來源登錄。
- 本機字型：使用者確認後保存 TTF／OTF／TTC 複本及雜湊，啟動核對後加入程式字型；欄位套用時綁定資產。字型損壞／失聯會阻擋正式輸出，不默默借同名系統字型；不安裝系統、不隨包重發字型。
- 同家族不同檔案版本本版保守阻擋；完整字重、精確系統字型版本、替代審核與自動修復仍待續。
- 模板發布資料與審核事件同一交易；失敗不改畫面物件為已發布。

## 驗證及限制

本地 Linux 50 項測試通過，包括新 Python 程序載入字型、雙作品重開與切換、舊標記遷移、歷史恢復、過期寫入、模板學習版次與來源防混配、發布交易失敗回復及字型檔變更／失聯阻擋。合成雙作品工作區已實際查看。

字型測試使用環境既有字型，沒有把字型文件上傳倉庫。新增資料表及舊 GUI 格式已做本地相容測試，沒有宣稱所有歷史私人資料均完成遷移驗收。自我驗證、Windows EXE 與實機效能等狀態見 `FIRST_VERSION_STATUS.md`；Windows 建置阻擋並未由本輪功能變更解決。
