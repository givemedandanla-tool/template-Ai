## 1. 交付目標

使用者必須能在Template AI本體實際操作完成：

**輸入人物／公司資料 → 取得完整初稿 → 調整資料相對位置 → 更正內容並返回 → 預覽與確認當次結果 → 通過檢查後輸出。**

本體透過既有桌面介面與必要改善承接完整流程，供使用者驗證工作方式。完整流程需接上實際的學習／生成／求解／量測／狀態與輸出；僅有底層函式、JSON、分散工具入口或card-interface示例不代表達標。

操作邏輯、資料／意圖與結果語意作為未來網頁／手機共用的基準。桌面可用適當的滑鼠、鍵盤及既有畫布／控制實現，不要求先複製手機外觀、觸控手勢或另做一個網站。

## 2. 必須具備的本體互動

| 階段 | 使用者可完成的事 | 必要保護 |
|---|---|---|
| 輸入 | 填寫人物、公司與聯絡資料，保存穩定欄位ID及歸屬 | 重複字串不能合併成同一資料；更正範圍明確 |
| 初稿 | 使用實際核心取得一張完整可閱讀稿，滿意可直接往輸出 | 不要求先排空白畫布、手選模板或調字級／字寬／行數 |
| 微調 | 指定某筆資料的相對位置，看到回饋、重排結果及無法處理的原因 | 不改主人、不刪內容、不覆寫全域模板；政策不允許的操作要阻擋 |
| 局部更正與返回 | 更正電話等內容後回原稿，保留仍有效的位置要求 | 新資料無解仍保留；舊預覽標stale且不得確認新版 |
| 復原 | 撤回／重做版面意圖 | 保留目前已更正資料，過期或不存在對象要說明 |
| 預覽、確認與輸出 | 看完整內容、確認確切版本，依格式與資格輸出 | 確認不代替模板／規則發布、資產與正式Gate；不借其他尺寸PASS |

本體專業後台已核准的設計編輯能力維持原範圍；一般產稿流程不強迫使用者操作文字尺度與單雙排控制，未來客戶端已撤回的控制不恢復。

## 3. 代表性端到端驗收（規劃，尚未執行）

1. **直接完成**：輸入已核實人物／公司與資產，取得實際核心初稿，不做微調即可預覽；當前全部正式Gate成立時才允許正式輸出。
2. **位置與資料分離**：指定手機在市話下方 → 更正手機號碼 → 返回原稿保留關係 → 撤回排列仍保留新電話 → 重新預覽／確認當次結果。
3. **失敗保留**：更正後資料在核准規則下放不下，保留新值、顯示原因及過期預覽，不截斷、不縮pt解圍、不借舊確認輸出；修正後重新求解／驗證。
4. **同一版本與依賴**：畫面、確認與輸出使用同一資料／版面／模型政策／字型Logo依賴；晚到結果不得覆蓋新修改，重開依既有核准恢復機制重新核對。

這些情境細化既有AI-LEARN-07／08驗收，不新增完成數。單一尺寸／人數／平台通過不可泛化成所有情境通過；正式來源或資產不足時，只能以待驗預覽呈現實際狀態。
