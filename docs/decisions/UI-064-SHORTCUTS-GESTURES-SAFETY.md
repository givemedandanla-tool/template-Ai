## 1. 核准的核心 GUI 行為（D）

1. **成熟習慣優先，快捷鍵應可探索**：初始預設參考 Windows 與常見設計軟體之熟悉的鍵盤／滑鼠操作習慣，提供滑鼠可點選的等價入口、功能選單提示、快捷鍵總覽及目前模式說明。**尚不鎖定完整按鍵對照、修飾鍵組合與移動步距**；須於未來技術／可用性研究核對作業系統保留鍵、輸入法、輔助工具與衝突後決定，不假稱已完成實機驗證。
2. **先判斷焦點，再判斷模式，最後驗證目標**：熱鍵派送必須依「目前取得輸入焦點的控制項 → 明確的操作模式 → 本次選取的候選／尺寸／物件 ID 與可編輯權限 → 指令可用性」逐級決定。處於文字輸入框、數字欄位、搜尋欄、下拉選單或輸入法中文組字期間時，方向鍵、Backspace、Delete、Enter、Esc 等應先遵守該控制項預期的輸入行為，**不得因舊畫布仍有選取便暗中移動、刪除或修改物件**。
3. **操作模式可見、指令作用範圍明確**：清楚區分「文字輸入」、「實體物件編輯／選取」、「畫布視角平移／縮放」、「AI 辨識標記框／校正」、「批次對齊或屬性操作」等既有模式；工具列或狀態區呈現正在使用的工具、選取對象、候選與實體尺寸。若目前焦點／模式／物件已不適用，快捷操作顯示簡短原因或保持安全無動作；不能使用已過期選取 ID 或錯誤人物／公司歸屬。
4. **鍵盤與滑鼠的語意不得偷換**：在畫布可進行移動、毫米級鍵盤微調、拖曳、吸附與縮放；視角平移或視窗倍率調整**僅改 viewport**，不能影響 X／Y、文字比例、群組、完整複合 Logo、字級、裁切與安全區。AI 標記框拖拉只改受控標記草稿，不改真實 Illustrator 物件；所有模式切換應顯示當下操作對象。滾輪／修飾鍵的預設優先權應避免捲動面板、編輯數值與畫布倍率三者衝突；未釐清焦點時不進行不可預期的變更。
5. **適度自訂與衝突診斷**：允許使用者對安全且適合的常用指令自訂快捷鍵；系統須檢查同一作用域／不同模式的歧義、Windows 保留按鍵、文字編輯常用鍵、輸入法及必要無障礙路徑。衝突時顯示「新設定／既有用途／生效範圍」與可執行替代方案（取消、更換按鍵、還原預設），不得默默覆蓋重要功能或讓同一按鍵在不明模式下同時觸發兩種編輯。釘選右側工具（UI-063）不自動改變快捷鍵的目標或優先級。
6. **風險分級防誤觸**：日常可回復的單物件檢視與編輯可直接操作、提供即時提示，不必每按一次方向鍵都彈窗；刪除含多人／公司共享關係的物件、批次刪改、解鎖核心受保護框位、套用到其他候選或物理尺寸等高風險行為，必須顯示**實際目標、影響範圍、相關鎖定／歸屬、預覽與必要確認**，且只能走既有合法授權程序。不同風險等級依可逆性與權限實際判斷，不能用「快捷操作」繞過 UI-010、034～036、061 的保護與發布審核。
7. **現有 Undo／Redo 的作用域清楚**：沿用既有內容編輯與標記的 Undo／Redo 語意，按鍵需作用於**目前有焦點的文字編輯控制項**或**目前明確選中的可回復工作交易**；不能因聚焦切換，撤銷到另一名人物、另一張候選、另一尺寸的未知操作。對物件移動、批次對齊等應記錄可理解的動作描述、修改前後版本及精確受影響清單。視角縮放／平移不可混同為內容變更，也不可讓一次 Undo 被誤解為正式客戶主檔或已發布模板回滾。
8. **版控柵欄與部分可撤銷性**：若動作後輸入資料、候選、人工編輯版本、模板 `style_version_id`、來源或 Logo 已改變，Undo／Redo 必須先核實依賴與可逆範圍；版本衝突可提供差異對照／人工解決，不得強行還原已被其他新動作合法更新的物件。既有 UI-059 的晚到 AI 防護和 UI-061 的跨候選同步／局部回復仍有效；未落盤內容也不得被描述為已安全保存。
9. **失敗與中斷行為清楚**：按 Esc／取消時應有明確模式語意，例如關閉臨時選單或退出尚未提交的操作，**不能不經確認取消已合法保存的工作、整筆刪除、全域放棄候選或繞過印前 Gate**；長按、重複觸發或高負載狀況須避免重覆提交交易，必要時顯示正在處理與拒絕重入。錯誤、選取失效或暫時無法操作時，保留人工編輯、清楚告知原因。
10. **低配與無障礙可用性**：快捷鍵只是操作加速選項，不可要求所有人必須記住；所有關鍵功能有滑鼠／明確 GUI 操作路徑，焦點、工具模式及風險提示應可辨識。輸入法組字和文字游標移動不應引起畫布卡頓；遵循 UI-051／058 的資源限制，效能／實際鍵位由未來 Windows 裝置測試確認。

## 2. 重要的跨決策邊界

- **UI-012、034、036**：物件移動、毫米座標、三向選取、多選對齊、鎖定、已發布模板與原始 .ai 的保護不變。
- **UI-037**：縮放／平移只是視角，不是修改真實物件幾何，螢幕 100% 也不自動代表實體毫米 1:1。
- **UI-039**：在原稿上標記 AI 辨識候選框，不等於編輯 Illustrator 真實物件；不同模式快捷操作不得混淆。
- **UI-013、016～020、023、027**：字級固定、人物 ROOT／公司／Logo 強歸屬、各尺寸 Logo 合法來源、印前硬性 Gate 不能因快捷鍵／Undo 被旁路。
- **UI-059～063**：依賴增量重算與編輯版本柵欄、跨尺寸同步與局部回復、跨模式安全返回、右側固定工具及工作狀態顯示均維持一致。
- **UI-045／048／055**：快捷鍵不可靜默更新正式客戶主檔、改變完整權限核准排序或將人工操作自動當作訓練真值；UI-056 D 補樣功能仍是後期低優先級候選。
- **Anti-proliferation**：只能延伸既有 GUI command／Undo／工作狀態與資料層，不另外新增平行快捷鍵系統、第二個撤銷引擎或永久操作歷史資料庫。

| 快捷鍵與 Windows／輸入法／同作用域命令衝突 | 自訂設定被拒絕或需明確重新指派，不會偷偷讓兩個行為同時生效 |
| 釘選文字工具後切換選取 Logo | 快捷鍵仍依現行焦點／選取物件合法性判斷，不修改不適用的 Logo |
| 對跨人物的多選執行刪改 | 顯示受影響名單、不可處理項及風險；未經核准不修改 |
| 按 Ctrl+Z 且目前正在編輯某文字欄 | 只撤銷該欄文字輸入中對應動作，而不是跨候選移動舊版物件 |
| 舊運算結果晚到、使用者重做或撤銷先前修改 | 版本柵欄擋下過時交易，保留目前已確認的人工變更 |
| 在印前阻擋狀態按快捷鍵試圖跳過驗證 | 仍維持正式輸出禁止狀態；只提供合法修正入口 |
