## 已核准範圍
1. 預設突出 AI 推薦的最佳排版，但若搜尋未完成或未有可證明的全域最佳，不得誤稱最優。
2. 使用者可展開其他候選方案，檢視預覽、優缺點及驗證差異。
3. 明確區分正常、警告、阻擋；低把握草稿不得標示為正式合格。
4. 點選問題可定位對應人物、公司、欄位及版面物件，並顯示原因與修正入口。
5. 允許人工修正，遵守 UI-059 人工編輯保護、版本柵欄與重驗規則。
6. 任何未通過當前實體尺寸完整硬性印前驗證的候選，不得正式輸出。
