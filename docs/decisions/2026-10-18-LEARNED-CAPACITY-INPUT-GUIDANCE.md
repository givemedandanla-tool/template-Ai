# 訪談結論：先學容量與字串適宜區間，再提供輸入限制與引導

- 日期：2026-10-18；狀態：USER_DIRECTED_TRAINING_AND_INPUT_POLICY。工程schema、估計方法與數值仍待實作／驗證。
- 使用者原文：「我們先根據訓練結果，得到最多允許多少欄位和最適字串數區間，互動端再做出限制與引導。」
- 依本輪「筆數增加／字串過長」上下文，字串區間記為各類欄位的字串長度與實際文字占用範圍。尚未指定任何數值。
- 本結論取代第一題先選A/B/C重排範圍的訪談順序；不把未選的選項當核准。先建立有證據的容量與適用條件，再落地引導及限制。

## 1. 確認方向

作品／設計家族訓練 → 歸納欄位容量與字串適宜區間 → 用真實文字量測、求解及品質驗證校正 → 形成版本化能力profile → 本體輸入與產稿互動依profile引導／限制 → 實際結果仍逐次通過正式Gate。

欄位數與字串長度分別記錄、聯合驗證。資料筆數相同仍可能因字型、語系、文字組合、Logo占位、人物／公司群組不同而改變容量；各欄位個別落在區間內，也不保證所有欄位同時取最大值能排下。

## 2. 三種資料不可混同

| 記錄 | 意義與用途 |
|---|---|
| observed_range / observed_max | 已見訓練作品的描述統計；不等於可允許上限或最佳範圍 |
| recommended_range | 由有效樣本、品質偏好與獨立驗證支持的適宜區間，用於引導；短於／長於區間不自動代表不合法 |
| validated_admission_limit | 在明確尺寸／家族／角色組合／固定pt／資產／政策範圍內驗證的允許邊界；發布為可執行規則後才作限制，仍需當次實測與Gate |

「最多允許」是有適用條件及證據的能力限制，不宣稱已證明任意版面的數學全域最大值。保留best_found、validated、UNKNOWN／SEARCH_INCOMPLETE等狀態；搜尋逾時不能變成無解或硬上限。

## 3. 需要學習與保存的參數

- 條件：成品尺寸、家族／規則／模型／政策版本、人物／公司數與歸屬、欄位種類組合、實際字型face與固定pt、可用容器及合法拓撲、Logo／固定物件占位。
- 計數：邏輯資料欄位數與實際印出物件數分開；共享來源每個印出實例仍占空間，不以去重來源省略印出負擔。
- 字串：按欄位語意／語系保存grapheme長度、實際shaped寬高、合法換行及行數；字數只是易懂的輸入引導，不取代字形量測，也不作改pt理由。
- 聯合容量：總欄位與各群組／角色容量、字串長度組合、必要欄位、重複／可選／收合／換列條件；保留可行見證與失敗反例。
- 證據：去重lineage支持、資料覆蓋、誤差／不確定度、品質標籤與評估方式、驗證結果及來源／依賴版本。缺資料保持UNKNOWN，預設10pt不當真值。

輸入尚未確定家族時，參考當前核准可用家族的能力及相容映射；不能拿單一模板較低上限提前淘汰其他合法家族，也不能將各家族不同條件的最大值拼成不存在的可行組合。

## 4. 本體互動與品質界線

在既有本體輸入流程顯示有依據的建議／風險／限制及原因，不要求使用者自行選字級／字寬／行數或猜排版參數。沿用已核准的資料保存、輸入預警與當次驗證；不截斷資料、不悄悄縮pt、不用舊確認輸出新版。範圍外或未知時保留資料並明示狀態，不把風險預估當已驗證無解。

容量profile的准入條件、限制行為與例外需依核准規則／政策落地；統計高支持率不會自行授予規則啟用權。獨立網頁／手機仍延後，未來重用同一profile及核心驗證。

「最適」尚需明確品質目標：版面品質／風格保留與資訊容量如何取捨。純粹訓練分位數或單純放得下不能作美學真值。此為下一個訪談重點，尚未決議；未改已核准字級、可讀性／來源／Logo／正式Gate。
