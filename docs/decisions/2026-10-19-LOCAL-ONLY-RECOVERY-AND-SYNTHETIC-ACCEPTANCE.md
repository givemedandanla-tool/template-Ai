# 本地原稿、雙路還原與合成驗收

使用者確認並授權開始實作：私人作品、字型、資料庫及實際訓練留在 Windows 本地；不以提供作品給 Codex 作為開發前提。GitHub 只保存程式、決策、合成案例及匿名證據。延續既有 8 工作包／50 條，不增加完成分母。

## 當前實作與驗收契約

1. AI01/03：最大化重用 Inkscape，分開保留可編輯文字轉換與外觀還原；對 PDF 相容 AI 保留原始 PDF 文字／glyph 證據。轉換失敗允許可追溯後備；比較原始渲染與轉換渲染，失真不能靜默當訓練真值。
2. AI01/03：重用本機 Windows 字型來源盤點、fontTools、Qt shaping 與既有 OCR。以原始文字／OCR 候選和欄位影像，搜尋本地字型及文字幾何；無 fallback、無唯一答案時保留歧義，不把外觀相似當二進位身份證明。缺字、預算、不可讀資料均有明確原因。
3. AI01/03/04：支援多 run／多字型及 label-value 結構，保留來源座標、字元區間、實際字面、信心與來源失效邊界；完整文字與資料歸屬不遺失。
4. AI03/05/06：補齊分散、物件間距、容量／適合區間校準、實際排序特徵與本地模型資格流程。模型以本地資料隔離驗證後啟用；不要求把私人驗收資料上傳雲端。合成驗收不取得真實生產資格。
5. AI07：本體提供診斷入口與可預覽分享報告：缺少什麼、哪階段、影響、已試方法、補救及版本。分享採白名單，預設排除原文字、檔名、路徑、客戶編號、字型名與檔案、圖片、原始日誌及原稿 hash；沒有自動上傳。
6. AI02/08：有已知真值、不同來源與獨立封存案例的合成作品測試，驗證匯入→觀察→共用學習→模型／規則→新輸入排版。保存失敗與反例，不用同一公式同時生成答案及判定正確。退化、撤回、重啟及穩定輸出亦須驗證。

## 證據分類

分開報告 SOFTWARE_IMPLEMENTED、SYNTHETIC_VERIFIED、LOCAL_REAL_DATA_NOT_RUN、DEVICE_NOT_RUN、UNSUPPORTED，不以全包 PARTIAL 混淆未寫程式與尚未實機驗證。原 50 條及舊進度不因更名或自製樣本增加完成數。

原生 Illustrator 私有結構完整還原不預先保證；可用來源優先，後備方法與資訊遺失要可診斷。OCR 只提供文字線索，字型需另外渲染比對。字級、字寬、欄框、切齊及分散由核心規則決定，不恢復客戶細參數控制。獨立網站／手機／EXE 仍延後。

## 工程依據與預定驗證

重用 Inkscape CLI 的內建 PDF 文字匯入與 Poppler 外觀匯入兩條路線、Qt QPdfDocument/QTextLayout/QRawFont、fontTools 字面與 cmap、Tesseract TSV；影像比對採對稱距離變換與重疊誤差，保留可識別性與搜尋預算，避免單靠字寬或 OCR 信心猜字型。依本機已安裝版本 CLI help 及既有開源模組驗證，不宣稱使用商用私有實作。

預定 checkpoint：LOCAL-RECOVERY-BEGIN、LOCAL-RECOVERY-CORE、LOCAL-LEARNING-VERIFY、LOCAL-RECOVERY-FINAL；每可恢復里程碑和約 10 分鐘保存，GitHub fresh-fetch/tree 核對後才稱已持久化。
