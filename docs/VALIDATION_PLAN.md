# 驗證計畫與開發關卡 v0.1

狀態：**PLANNED / NOT VERIFIED**。下列皆是未來驗收標準，尚無 PASS。

## Gate 0：來源與既有資產盤點
- 盤點現有名片自動排版程式及授權；標明可直接重用、需改造、不能重用。
- 每個第三方依賴留來源 URL、精確版本/commit、授權、Windows 支援、維護風險與替代方案。
- 以匿名化測試作品建立多作品、註解、異形、不同尺寸、缺字型、效果外框的真實樣本集。

## Gate 1：Illustrator 解析
- 真實 .ai 文件的多設計切分、原生文字/效果、物件座標、字型狀態、人物/公司/Logo 歸屬有可人工核對的測試報告。
- 無法判定時回報 UNKNOWN/REVIEW_REQUIRED，不臆造欄位或尺寸。

## Gate 2：去重與增量
- 位元重複、內容近似、作品重複、模板等效分層測試；來源保留；更動/未更動檔案增量分析有可驗證紀錄。

## Gate 3：學習與模板
- 歷史重現、未見資料測試，避免同一設計不同另存檔同時進訓練與測試。
- 字級/水平縮放/對齊及適用條件可追溯；未知字型不假稱精確。
- 模板數量不以低品質湊數；人工發布及版本回復有效。

## Gate 4：排版與無解
- peopleCapacity、同尺寸模板匹配、人物與公司歸屬、等效欄位群、特製排版、硬限制與無解報告皆有測試。
- 不合格候選不可進入正式輸出。

## Gate 5：PDF/PNG/JPG 輸出
- 真實字型與尺寸、文字完整、水平縮放、對齊、安全區、印刷幾何、向量品質與不同格式一致性驗證。
- 初期不測試 .ai 輸出，不能將其列為已完成。

## Gate 6：完整閉環
- 以從未參與訓練的真實匿名化案例，完成匯入→學習→審核→排版→驗證→輸出。
- 提供失敗案例、缺口與復現步驟；獨立複核通過前不可宣稱正式驗收完成。

## 優先研究風險
R1 Illustrator 原生文字與效果解析；R2 字型未知與尺寸真值；R3 多設計切分與語意歸屬；R4 新尺寸泛化；R5 排版美觀驗證；R6 依賴授權與可分發性。
