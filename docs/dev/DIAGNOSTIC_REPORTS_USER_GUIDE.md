# 問題報告：程式內閱讀與離線保存

v0.1.26。正式驗收狀態以STATE／REQUIREMENTS為準，本文不是完成證據。

1. 在「排版與輸出」按「輸入問題報告」或「候選問題報告」；模板可從選單「當前模板問題報告」進入。沒有候選時會報告缺少候選，不把它說成全部模板無解。
2. 「訓練品質」選取問題後按「選取作品的問題報告」；只檢查該作品，列出來源健康與標記問題。「分類評估」可對選取的已保存評估產生報告，保留實際分母／TP／FP／FN，但不聲稱工具執行了模型推論或品質通過。
3. 當次單worker視窗可開「當次進度／問題報告」，保留實際完成、失敗與未開始數；進度繼續變動後，舊預覽不能保存為目前快照，需結束／取消後重新產生。
4. 報告的人類閱讀與JSON頁面呈現同一份安全快照。發生環節、影響環節、數值、版本、未知與實體印刷未驗證均保留。固定字級不變，缺字型的量測寬度用null，不是假0。
5. 按「另存安全報告ZIP」，選既有本機資料夾。ZIP內只有report.html、report.json、manifest.json；解壓後不必開主程式即可用瀏覽器閱讀HTML或讓GPT讀JSON。取消、磁碟錯誤、權限不足及撞名不報成功、不覆寫原檔。
6. 用選單「開啟歷史診斷報告」可唯讀重開。只接受本工具固定schema與封裝，不執行外來HTML或解壓到任意位置。checksum只證明檔案一致，不證明作者可信、內容正確或是當前PASS。
7. 選取問題按「核對版本並定位」。同Library、私有索引有效及資料／來源／字型／模板版本相符才可定位；已異動、不同Library、索引失聯／到期則保留歷史閱讀。無可靠欄位識別時不任意定位；未保存的主畫布／屬性不會被導航覆蓋。

安全交接版只保留固定問題類型、必要數值與每份報告的匿名代號；姓名、電話、Email、公司原名、原始檔名／路徑、原稿、字型、圖片、自由備註與例外原文不加入ZIP。省略是實際檔案內容的白名單，不是畫面打馬賽克。產品不自動上傳或寄送，需由使用者自行分享；開發用GitHub持久化是另一流程。

定位索引只保存在本機Library／diagnostic-locators，預設7天，啟動／讀取清理；選單可立即清除。它不包含原文個資，不隨ZIP分享。程式關閉期間不承諾即時清理，刪除不保證鑑識不可恢復。手動保存的安全報告不自動刪除。

預算：單次同尺寸模板200、輸入列200、輸入欄位2000、問題／量測各2000、ZIP解壓總量2MiB；超額明示省略或請縮小範圍，不當全部檢查。報告背景封裝失敗後可以重新產生。

報告是歷史、非正式問題記錄，不會修復資料、替換字型、修改模板／訓練、解除Gate或保證視覺一致。完整UI-048仍最後實作；目前驗證只用匿名合成／合法去識別資料，不代表真實個資生產權限已就緒。
