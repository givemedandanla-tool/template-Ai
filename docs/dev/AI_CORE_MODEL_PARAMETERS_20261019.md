原稿頁面字級與作品字級分開：均勻物理縮放 `s` 得到 `pt_work=s×pt_source`，字距／詞距毫米值亦按比例換算。非等比變換不能唯一推出單一pt；必須獨立量測作品座標，並明確說明字寬與間距的量測座標。管理者來源審查可以填實測值，客戶稿件不顯示這些控制。

聯合回歸按獨立來源群平衡：每群先移除精確重複配置，群內每筆權重為 `1/n_group`，標準化平均與標準差也用相同權重，再最小化加權平方誤差與Ridge懲罰。GMM提議模式時每來源群提供一個代表；原稀有配置及反例仍保存。偏好訓練先平衡來源群，再平衡query與比較，不讓同一來源80個query壓過其他作品。

風格鍵使用實際字型hash／字面、對齊、分散／flow與label行為。審查者、來源編號、證據引用與本機路徑只作追溯，不用來把相同風格切成不同模型。完整來源證據仍附在觀察／模型依賴中；撤回、字型變更或證據變更會使相關模型失效。

本體操作傳入穩定資料ID、owner、內容、產品尺寸及相對關係。核心先尋找合法的當前家族變體，再比較相容候選；不受影響欄位保持相對拓撲，字級／字寬／欄框可在核准聯合規則內一起改變。有多合法解時使用版本化預設與穩定決勝；重複下單先檢查既有已確認檔案的確切bytes/hash，不因新模型改版而重排。

工程起點不是訓練結論：HDBSCAN epsilon=.05在robust特徵空間，GMM最多3個候選mode、Ridge alpha=1、近鄰支持距離1.5與有限搜尋預算等均為版本化工程設定；不是印刷mm公差，也不是已經真實驗證的最佳值。真正欄位上限、適合字串區間、交換條件與風格範圍仍須從合格作品及隔離驗收取得，不把64欄處理預算當學得容量。

正式資料提供後依序：來源／字型與權利用途核對→來源run和欄位／群組／量測對應→已知lineage隔離TRAIN/VALIDATION/HOLDOUT→TRAIN擬合／保留反例→封存實際輸出及獨立偏好標註→分群與四類風格分項驗收→明確版本政策啟用。私有原稿、字型及DB留在既有受控資料／備份；GitHub保存程式、匿名指標、決策與接續狀態。
