## 資料如何變成共用模型

1. **可觀察資料**：來源檔／頁／作品／欄位、完整文字與角色／歸屬、容器幾何、字型檔與實際字面、pt／水平縮放／字距、文字群與來源變換。每項記來源、單位與 OBSERVED／DERIVED／UNKNOWN。OCR 提供文字候選，不能單獨證明字型身份；像素估計不能冒充原生 pt。
2. **訓練准入**：核對作品、雜訊、完整內容、來源／字型與用途；按 lineage 去重並分 TRAIN／VALIDATION／HOLDOUT。同檔的不同尺寸／改版不能靠複製變成獨立支持。核對好的部分才形成可學觀察。
3. **共同家族**：結構相容特徵交給 HDBSCAN，至少五個獨立來源群支持共同家族，孤例保留。功能風格身分不含每件作品不同的 run ID；不逐作品產生一個全域模板。
4. **條件規則**：以實際文字需求、尺寸與欄位組合預測聯合字面／欄框／位置向量。群平衡 Ridge 控制回歸；原始及回歸殘差的 GMM 提議不同風格，再以 mixture-of-regressions BIC 比較，避免把連續尺寸誤當多個離散風格。已知支持內仍保留多風格與低支持項，不強行平均。
5. **實例化**：由家族／文法產生有限拓撲及合法欄位指派，用 Qt 實際字形量測及 Kiwi 約束求解。保留完整資料、歸屬與客戶指定的相對位置；字級、字寬、框位與分散由核心規則決定。有限搜尋的狀態／預算與未知條件明列。
6. **預選與重用**：硬 Gate 後以 group-balanced pairwise logistic 排序，加入實際聯合風格距離等特徵；版本化決勝確保同有效輸入穩定。已確認稿重複下單優先沿用精確封存檔案，不以 JSON 重算冒充相同印紋。

## 目前可學與不可自由指定的參數

| 參數層 | 例子 | 來源／用途 |
|---|---|---|
| 資料需求 | 語意種類、筆數、owner、實際 shaped advance、字串／字面組合 | 新輸入與來源觀察；不是只看字元數 |
| 容器能力 | 容器／群組、角色條件、相對位置、分割／收合、可選／重複 | 多作品共同觀察及已核准語意政策 |
| 文字風格 | 字型／字面、pt、角色比例、hscale、tracking、換行、baseline | 已核對來源；推估保留 DERIVED，缺證據 UNKNOWN |
| 分散與間距 | 詞邊界、塑形字元群、末行、零邊界、額外 gap 上限、物件等距 | 明確 source-reviewed 規則；詞／字／物件不混為一談 |
| 條件相容 | 資料種類在不同欄位共用需求、不同角色在同容器的條件替代 | 先核語意／owner／政策，再檢查實際文字與幾何；不是同大小就可任意交換 |
| 聯合適合區域 | 字型／家族／尺寸／欄位組合下，完整輸入需求的實測可行及合格風格 | 獨立 VALIDATION 群校準；最大已驗證筆數不當全域硬上限 |
| 偏好 | 同 query 的已標記比較、候選特徵權重 | 偏好／修正／政策分開，輸出成功不等於美學合格 |

自動增加資料量後，模型可重新估計家族、係數、支持、風格分組與排序權重。這不是任意自行新增語意欄位、解除印刷政策或放寬准入。工程超參數及正式啟用政策仍具版本、核准與驗證要求；未知新風格不能靠幾千件資料數量自動變成已支持。

## 機率與幾何的使用方式

Ridge 使用群平衡權重，求解加正則項的平方誤差；同源重複不放大支持。BIC 比較不同風格回歸的擬合與複雜度，訓練殘差只作擬合診斷，不直接當泛化信心。

容量校準按獨立來源群計成功／失敗，同群任一實例失敗即不把該群算完整成功。對 `s` 成功、`n` 群，單側 Clopper–Pearson 下界為 `Beta.ppf(alpha, s, n-s+1)`（`s=0` 時為零）；還需達最小群數、門檻與聯合需求支持距離。HOLDOUT 不回填擬合；校準另存版本，不改訓練快照。容量結果是特定條件的實證區域，輸出前仍驗實際排版。

字型比對以本機字型檔／face 的實際塑形與渲染，對照裁切墨跡的距離與重疊，聯合搜尋幾何；不靠字寬單值或 OCR 信心宣稱身份。相近候選、未搜完、無物理標定、缺字與不支持結構均保留未知／候選或拒絕。

實際重用 [Inkscape CLI](https://inkscape.org/doc/inkscape-man.html)、[Qt QTextLayout](https://doc.qt.io/qt-6/qtextlayout.html)、[fontTools](https://fonttools.readthedocs.io/)、[Tesseract](https://tesseract-ocr.github.io/tessdoc/)、[scikit-learn](https://scikit-learn.org/stable/)、[SciPy](https://docs.scipy.org/doc/scipy/)、[Kiwi/Cassowary](https://kiwisolver.readthedocs.io/)。原始工程參照與實際查閱範圍另見 `AI_CROSS_WORK_ENGINEERING_REFERENCES.json`。

商用影像找字型／Retype 類流程提供「辨識→候選→核對→可編輯」的操作思路；本實作使用上述本機元件，不宣稱複製商用私有模型，也不調用其付費 API。Figma Auto Layout、條件布局生成研究等是文法／約束設計參考，示例排版引擎不當正式印前能力。
