# 家族與專業規則工作台

入口：本體「模板目錄」→「家族與共用規則」，或既有設計學習視窗的第4頁「家族與專業規則」。這是管理者的專業工具；客戶仍只調整有意義的相對位置，沒有字級、字寬或單雙排控制。

家族是一組從多份作品學得、能承接多種輸入的共用規則。來源作品、家族、固定模板、單次生成實例及確認稿分開保存；瀏覽家族不會為每份作品建立全域模板。

## 大量管理

1. 用尺寸、人物數、欄位數、資料種類、支持數、未知證據及健康狀態篩選。搜尋結果每頁48項；切頁保留明確勾選。保存工作集後，重開會按當時資料重新查詢；批次則另存固定的家族／模型版本清單。
2. 「代表來源」顯示常見、邊界和少見的TRAIN樣本及尚未覆蓋的分層。勾選兩個家族可並排看已核對的來源裁切與框線；差異含角色、聯合字面、文法、關係及已校準容量。近似不會自動合併。
3. 先在單一家族建立一個受控規則操作，再到「批次與接續」預覽勾選家族的逐項差異、不可套用理由及固定版本。核對後才能執行；可在目前項目結束後暫停，重新開啟後接續。局部回復只撤銷未被後續人工修改的草稿，其他項目明確跳過。
4. 原有來源／字型批次修正、失聯重連、字型中心及本地備份入口沿用。不要把同名、同框或高信心當作已核實的來源。備份私人庫到自己的本地位置；GitHub只保存程式與匿名測試證據。
5. 「差異與影響」可依目前模型、來源頁選定檔案或字面頁選定字型查看依賴數量及分頁明細。既有確認稿保留原始檔案；來源、字型或權利變更仍可能阻擋再次使用。

## 單一家族

選定家族後建立規則草稿。草稿有版本、操作歷史、Undo／Redo及衝突保護；原模型保持可追溯。

- 概覽：人物／公司樹、欄位、畫布與來源同步選取。原有物件移動、對齊、群移、鎖定等工具仍在原編輯畫布使用。
- 角色／容器：查看來源支持、語意細類、歸屬與政策，限制已觀察過的相容組合，指定合法結果的預設順序。相同電話大類不代表市話與手機可無條件互換。
- 關係：查看有來源支持的切齊、基線、間距等關係，提出OFF／SOFT／HARD草稿；明確局部操作意圖優先，其他關係依適用範圍保持。硬關係在求解後另做獨立重驗。
- 條件變體：檢視已觀察的可選欄位、人物／尺寸組合、文法和條件幾何，限制允許的模式與設定預設排列。沒有資料支持的新模式不會被虛構為合法。
- 聯合字面：整組核對字型、pt、字寬、框、字距、分散及換行風格；可指定已支持來源風格的優先順序。容量顯示條件化驗證結果；沒有校準就維持未知，不能用觀察最大值當保證上限。
- 來源：選來源與欄位後開啟原稿、事實標註、復原診斷或字面核對。複合文字須完整覆蓋來源run；固定標籤須匹配原稿文字hash；圖示需實際來源關聯與必要權利。原生已知、人工有依據的推導與UNKNOWN分開保存。先預檢，再明確提交；變動會使舊模型證據失效，需重新訓練／核對。

## 案例與版本

「案例試排」保存工程案例的資料、尺寸、政策與相對意圖。可從已確認的TRAIN來源建立重播案例，也可接收本體輸入會話，再把試排送回本體繼續微調。工程案例不會自動變成訓練真值。欄位缺失、未支持的Logo／歸屬、排版失敗及缺證據分開報告。

預覽實際執行既有文字塑形、排版與硬性檢查；比較短長文字、交換或局部移動後的結果。來源回歸可選代表集合或完整TRAIN成員加保存案例。代表抽樣、合成測試或有限求解預算都不等於全庫／正式印前合格。

核對草稿差異後才建立新的PENDING模型候選，不覆寫已發布模型，也不複製舊資格。可明確選擇預覽模型／回退；正式啟用仍使用既有資格Gate。草稿移至新版家族需明確rebase；不相容操作會拒絕。重新開啟工作台會恢復查詢、選取、草稿及案例位置。

本輪驗收範圍為Linux本體、程式生成作品、實際Qt畫面及SQLite大量索引；Windows真實字庫、私人原生.ai及實機印前另行本地驗收。未引入付費模型或自動上傳私人資料。
