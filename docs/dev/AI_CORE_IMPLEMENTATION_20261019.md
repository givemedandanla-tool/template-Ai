# 8工作包核心候選實作與驗證邊界

使用者授權持續完成8包；實際.ai作品與對應字型於2026-10-19確認「尚未提供」。目前8包皆部分實作、0完整驗收；保留原8包50條，不用合成測試宣告真實訓練完成。網頁／手機／EXE未開發；未啟用付費AI API。

本體入口：左側「訓練與原稿」→「共用AI規則／當次稿件」。管理者先沿用一鍵來源分析／作品標記／雜訊與事實核對，再對應原稿文字及授權字型、指定隔離集合，建立共用規則候選並明確採用。當次稿件可輸入、產生完整預覽、相對拖動或選單操作、局部更正返回、復原位置而保留新資料、確認、輸出及重開接續。客戶稿件沒有字級、字寬、字距或單雙排細調控制。來源審查的管理者參數與客戶操作分離。

結構分群不直接使用姓名、客戶ID或字串，也不因電話換成Email而複製家族。所有框貢獻4×4佔用網格、物件／歸屬群計數與面積，另以16個幾何排序位置和字級相對層級描述；超過16個框仍保留在原觀察／規則。絕對來源pt保留在聯合規則。HDBSCAN epsilon=.05是robust特徵空間的可調工程起點，修正匿名自製近重複變體51家族的過度切分；不是mm印刷公差或已經真實驗證的最佳閾值。封存集不得回填擬合。

相同有效輸入包含穩定實體／欄位身分、資料、尺寸、明確關係與資產版本，排除無關revision／新模型版本。不得由文字相等推定不同人的身分；取回既有確認檔案檢查實際bytes/hash及必要現行權利，不重新排版冒充重印。

正式資格要求真實授權來源／lineage審查、至少5獨立封存群、逐案資料完整與硬錯誤、群平衡可行率、獨立偏好及明確版本政策。只有已核對來源字型／切齊／字距／詞距／縮放的模型及匹配政策才能建立DESIGN_INSTANCE；不註冊成全域模板，沿用格式／字型／Logo輸出Gate。這僅限實測核心數位範圍，不等於物理印前能力。
