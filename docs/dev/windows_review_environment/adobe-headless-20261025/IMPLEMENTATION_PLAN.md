# 最小離線 Adobe 讀取引擎：執行計畫

使用者已明確要求全部完成並持續工作，直到交付能正確讀取 AI、且不能連線至 Adobe 的 review-tool。既有範圍仍包括原生字型檢查、每份文件獨立程序，以及通過驗證後精簡 review-tool 的 COM／Inkscape 重複路徑。

1. 保存已驗證的離線讀取基準與原始檔。原生除錯目前顯示 AppContainer 初始化失敗經 AdobeLinguistic 的例外／終止流程，正在解出詳細錯誤；不是已證明的網路依賴。除錯的例外指標掃描只作定位線索，不冒充完整堆疊展開。
2. 以精確受限的本機權限修正或完整斷網的 Windows 執行邊界解決初始化；失敗時不得退回未隔離路徑。每份文件新程序，取消或逾時必須終止所屬工作。
3. 在新副本排除非必要回報／登入／雲端／更新模組；只有定位具體行為後才考慮必要 DLL 的定點修改。保留每次變更與原始雜湊；不得把未簽章或載入網路 API 直接當作惡意證據。
4. 驗證原生字型替換檢查與 AI／PDF／SVG 輸出，作品幾何、文字、圖片及畫板都需有依據。所有真實讀取驗證均包含合成資料及指定私人樣本；私人內容不進公開證據。
5. 通過後整合 review-tool，移除已替代的部件路徑，保留其他 template-Ai 部件所需共用程式。做 Windows 產品回歸與網路拒絕正向／負向控制。
6. 只同步程式、合成測試與匿名交接至 feature/review-tool-v0.1.0，逐檔讀回確認。作品、字型、Adobe 配套及原始診斷只留本機。不合併 main，不打包發布。

本 checkpoint 是進行中保存；尚未交付產品、尚未修改 Adobe DLL，原生隔離未通過。既有全專案 governance check 仍因歷史證據過期失敗，本輪不升其資格。
