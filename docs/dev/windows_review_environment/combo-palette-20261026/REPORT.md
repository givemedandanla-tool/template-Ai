# review-tool 下拉清單配色修正

使用者回報資料種類及核對狀態仍為深底深字。原因是原先只設定 QMenu 與核對表單；QComboBox 的獨立彈出列表仍繼承深色系統 Base。此次為該列表明確設定白底深字、淺藍選取底及停用文字色，涵蓋資料種類、歸屬、核對狀態、字型款式四種清單。沒有改變選項資料、判讀流程、字型或引擎隔離。

## 驗證

- 修正前在 Windows 深色 palette 重現四個黑底列表，實際像素為 #111111。先前測試只涵蓋動作選單與表單，漏測真正展開的下拉清單；已補回歸。
- 淺色及深色 palette，各實際展開四種清單。一般與選取文字對比至少 7:1，停用文字至少 4.5:1；滑鼠及鍵盤選擇保留資料值，停用選項保持停用。八張合成畫面留本機，已檢視資料種類／核對狀態畫面。
- Windows 部件回歸 91 PASS、0 FAIL、0 SKIP，包含原動作選單測試。見 EVIDENCE.json 的唯一測試清單及來源雜湊。這不是重新驗證所有 AI 或打包版。
- 最初 UI 測試在原生視窗與動畫完成前取樣失敗；修正測試等待後先重現舊配色，再驗證修正。首次整組啟動因輸出父目錄不存在而未執行，建立新目錄後完成；原始記錄保留本機。
- 全專案 governance check 仍因既有歷史證據過期而失敗，與開工前相同；不升整個 Template AI 資格。

使用者已保存並正常關閉舊視窗，已用原工作資料與診斷目錄重新啟動來源開發版。來源版本仍為 0.1.0-beta.3.dev2，本次修正由 checkpoint／提交區分。資料、作品、字型、Adobe 引擎及原始診斷不上傳。只同步明列程式、測試、匿名結果與交接至 feature/review-tool-v0.1.0；不合併 main、不打包發布。
