# v0.1.25 本輪新增功能操作與未做範圍

只用匿名／合成資料。完整登入、權限與個資管理仍排最後；本版未宣稱生產環境可處理真實客戶資料。軟體核心是矩形區域自動排版，不以名片／門禁卡名稱決定能力。

1. **客戶資料**：在排版頁輸入人物資料，再從選單「本機客戶／版型與備份」人工建檔，輸入字串編號並核對確切模板版本。保留前導零；本輪建檔暫不接受公司綁定，避免把未支援語意靜默丟失。搜尋不建立成品，也不合併同名或共用電話的客戶。選中客戶後可選確切關聯版型預填本次；輸出頁「解除重訂版型限定」可回到其他模板搜尋。
2. **逐欄回寫／重複比對**：本次值可編輯，勾選欄位預設全空；先看三方差異再確認回寫。清空值是明確刪除候選，不輸入變更則不改。過期主檔拒絕覆蓋。Ctrl選兩個客戶可看雙方線索，身份仍UNKNOWN，**尚無合併／別名／拆分**。
3. **加密部分備份**：同一客戶視窗可做Scrypt＋AES-GCM加密SQLite一致快照；密碼至少12字，與備份分開保存，遺失沒有萬用還原。隔離還原只接受不存在的新目錄，不切換或覆寫目前資料。**只含資料庫；原稿、圖片、Logo與字型資產未隨包，不能宣稱完整可攜、可離線製作**；排程與完整資產備份尚未做。
4. **輸入提示與Logo尺寸庫**：欄位旁tooltip與輸入問題清單共用同一診斷，可點問題定位exact人物儲存格；字寬依固定pt及實際毫米量測，不用通用字數上限，預估不是硬性無解。選單「尺寸獨立Logo庫」的正常清單只顯示所選尺寸；勾選跨庫參考專區才顯示其他來源尺寸，全部只讀、未在新尺寸核准，**尚未執行AI新尺寸預測或目標審核**。
5. **當次排版控制與局部修改**：輸出頁「當次單worker／暫停取消」按真實模板分母計算，暫停／取消在候選邊界生效；結束後明確採用已算結果才更新既有畫布。資料或模板改變會阻擋舊結果。候選與輸入只在當次記憶體，**尚無跨啟動敏感暫存恢復**。局部修改先看exact框位毫米差異，只改目前候選＋尺寸，不改發布模板／其他候選；跨尺寸語意同步與局部復原仍待做。
6. **上下文與安全批次**：既有「安全多選／精確對齊」的右側可釘選文字工具；切到Logo或取消選取，不適用控制停用／清空。選單「多作品安全批次對齊」列出exact文字ID，逐作品預覽、確認後沿用既有ObjectEdit交易及歷史；過期項獨立失敗，已執行操作不重複套用。復原仍在既有物件歷史，較新人工修改會阻擋回復；不表示整卡PASS。
7. **來源重掃**：選單「來源根目錄安全重掃」只掃明確選定根目錄；是否含子目錄需明選。每檔兩次實際SHA及stat核對，列出新增／異名同內容／內容變更／等待穩定；離線不當永久刪除。不覆寫原稿、不自動匯入或學習。**事件監看、增量自動匯入與完整版本衝突處理仍未完成**。
8. **分類評估／隔離修復／重大重審**：在既有「標記品質／規則與可信樣本」新增分頁，先用已核准HOLDOUT資料集，再提供外部／人工的預測記錄與exact模型／解析器／OCR／規則版本。本工具計算分類TP/FP/FN、混淆與歸屬錯誤，**沒有執行模型推論，也沒有宣稱獨立品質PASS**。缺真值／無樣本顯示不足；近重複、客戶家族與正式統計門檻尚未驗證。由失敗案例建立的根因只是隔離假說，使用holdout設計修復即記錄需新獨立集。重大重審只對有明確規則依賴的歷史樣本，人工勾選後原子隔離、保留舊核准；新學習／相關模板使用被阻擋，**尚無全面模型／Logo／客戶依賴掃描及受控解除重審**。

UI-066沿用既有問題與定位；獨立報告R1/R2仍受阻，沒有自行選PDF／HTML。UI-067為機器治理對帳，**不算新增產品功能**。本輪達標是原75父需求中70項至少有實作，不是70項全部完成；各父題原FULL條款與剩餘範圍保留於REQUIREMENTS與SEVENTY契約。
