# 200個來源預檢完成後：目前下一步

適用已發布beta2的自動分析視窗；2026-10-23依真Qt匿名作品操作核對。私人檔名／作品不保存。

你看到「預檢完成：200來源，失敗0」，各列為「待啟動核對」「尚未分析」，代表只檢查完檔案，尚未啟動分析。失敗0不能解讀成200份作品已學習成功。

1. 沿用這份預檢，按上方LOCAL_OPERATOR右邊的「確認預檢並開始訓練」。LOCAL_OPERATOR可保留。
2. 核對確認視窗是這200個來源後選「是」。
3. 觀察「實際狀態」轉為「處理中」，以及「已分析作品」出現數字。建立持久工作前會再核對檔案／頁次，可能需要等候。

## 找不到開始按鈕

先最大化視窗。若右側仍看不到，點LOCAL_OPERATOR輸入框，按一次Tab，再按空白鍵，會操作「確認預檢並開始訓練」並開啟開始確認；核對後選「是」。真Qt已驗證Tab焦點確實到該按鈕，沒有拿私人檔案試跑。本地畫面尺寸尚未量測，不能據此斷言使用者螢幕解析度。

## 接下來的狀態

| 狀態 | 意思與動作 |
| --- | --- |
| 待啟動核對／尚未分析 | 還沒有開始，按上述開始按鈕。 |
| 處理中 | 正在分析來源。需要停止時使用「安全取消」，不要重複啟動同一批。 |
| 待必要審核 | 已產生結果但需要人工核對；按「開啟作品例外／品質中心」查看作品與問題。 |
| 失敗待處理 | 看「問題／待核對」內容；需要維護協助時手動匯出安全報告，原稿留本機。 |

分析與人工核對、樣本准入、共用規則學習及正式啟用是不同階段。此處開始按鈕沿用「訓練」名稱，不表示按下後自動取得正式模型資格。

## 面板待改進（尚未實作）

開始動作應固定可見；操作者欄改成次要資訊，窄視窗能換行／捲動。畫面需直接說「已檢查檔案，尚未分析」，並在建立持久工作／重新核對200檔時提供可見狀態。未完成學習時不得用成功樣式暗示模型已可生產。
