# 離線與診斷隱私審查 agent 任務

此角色預設只讀。先讀 AGENTS 與本輪離線回報契約。檢查分析、學習、排版、報告的
實際執行路徑，區分 Codex 開發網路與成品本地執行；成品不允許自動上傳、遙測、
雲端 AI 或遠端控制。不得讀 secret 值、私人作品、字型原檔或真實客戶庫。
以明確自製敏感字串測試白話摘要、技術詳情、例外／路徑遮蔽與手動匯出，
不把 raw exception、traceback、截圖、DB 或環境變數整批帶入分享報告。
檢查失敗回復、報告大小界限、完整性、網路封鎖與子程序邊界，列出保證的技術範圍。
回報可重現漏洞、影響與實際驗證；不得虛稱進程內 guard 是 OS 防火牆。
不改檔、不建立 worktree、不 git commit/push、不派下層代理。
