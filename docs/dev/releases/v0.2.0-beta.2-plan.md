# v0.2.0-beta.2 隨包Inkscape與局部變更除錯

狀態：AUTHORIZED_IN_PROGRESS，2026-10-22。使用者明確採用隨包方案並要求完善代碼、依發佈規則打包與發布Release；同時要求研究合理除錯範圍。基底dev/v0.1-first-version／059af6de，既有beta.1來源8b95與公開資產不覆寫；新版本按既有規則beta.2，不合併main。

## 交付與驗收

- 隨包固定Inkscape及必要相依、授權和對應來源資料；先核對實際Windows散佈內容與來源義務，不只拷貝單一exe。
- frozen程式只選包內工具，即使環境變數／PATH／系統已安裝版本存在；缺檔、版本錯誤、被更換時明確失敗，不靜默回退系統。來源開發模式仍支援既有外部工具，區分兩者政策。
- 工具身分納入新分析快取，舊來源快取／模型／已確認稿歷史不被新版悄悄覆寫；保留人物歸屬／stable ID／固定pt／ScaleX／輸出Gate。
- 先建立原先錯選系統工具的紅燈測試，再修正、跑精確路徑回歸；含包內與系統同時存在、包內缺少但系統存在、工具改版／變更、中文空白路徑。
- 原source／Qt隔離／證據治理與發佈檢查保持；日常小修改只跑影響範圍，發佈里程碑完整相關整合＋必要正式來源資格＋真正Windows EXE流程。
- 真EXE在有系統干擾與無系統Inkscape兩種情境驗證，記錄實際使用的包內路徑／版本／hash，執行合成匯入／分析／學習與原製作、暫停／續跑、定稿重播、安全報告。
- 不以mock、source-mode或只查version代替真成品；公開後重新下載、比對全部包內檔案與manifest／SHA。資料與使用者Windows／真作品／實印等原外部資格不自動升級。

## 除錯研究範圍

參照成熟變更影響分析／Test Impact Analysis、coverage.py／pytest-testmon、Python變異測試等公開資料，設計靜態反向相依＋動態測試關聯＋外部工具／設定／流程契約邊的保守聯集。列出選中與排除原因、資料有效性、不可省略安全底線；未知相依要擴大，不能把空集合當通過。測試挑選可視為反向可達性與帶權集合覆蓋問題，並驗證對錯誤路由等故障有紅燈能力。研究結論與可執行示範分開，不擴張全庫重構或新增付費平台。
