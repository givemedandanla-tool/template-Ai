# Windows x64 內部實測版

首次將目前AI學習、家族規則與桌面製作流程交付為Windows測試包。完整解壓ZIP後執行TemplateAI.exe，不需另裝Python。

- 下載TemplateAI-v0.2.0-beta.1-windows-x64.zip；不要只取走.exe或_internal裡的檔案。使用說明及授權在包內。
- 程式完全本地執行，不需要API key，不自動聯網或上傳作品。問題報告由您手動匯出並交Codex。
- 啟動EXE與既有模板製作流程不要求Inkscape。PDF相容.ai／PDF、SVG與一般圖片有內建備援讀取，讀取成功仍須核對來源資訊與資格；要擴大作品轉換支援範圍，可另外安裝免費Inkscape（驗證版1.4.2）。Inkscape與私人／商業字型均未打包，完整.ai私有內容還原不保證。
- 先用獨立資料副本測試，不直接升級唯一客戶資料庫。

## 驗證與限制

本版建置必須通過Windows程序隔離來源回歸與實際EXE的合成學習、輸入、產稿、預覽、滑鼠拖動、更正、重新確認、允許預覽輸出、安全報告、背景工作暫停／重啟及保存重播檢查。來源提交、工具與依賴、實際數量及包內檔案SHA256見release-manifest.json；檔案校驗見SHA256SUMS.txt。發布前後實際下載核對，證據保存在release-evidence/v0.2.0-beta.1分支。

這些合成驗證不等於真實作品品質、完整私人.ai還原、使用者Windows硬體效能、實體印刷或新手完整資格。正式輸出仍依既有來源與資格Gate，不因beta放寬。教學／外部知識庫方案仍待討論；網頁／手機仍延後。

未使用付費程式簽章；遇到安全提示先核對來源及SHA256，勿停用防護。

回報請附版本v0.2.0-beta.1、重現步驟及「問題與報告」匯出的安全ZIP，私人作品與字型留本機。狀態：已發布後仍待使用者本機確認。

跨平台驗證分工：完整來源回歸與原版GUI證據在Linux建立；Windows另執行16個適用模組（176案例，含安全回歸）及實際EXE操作。Linux特有字型／符號連結案例沒有冒稱Windows通過。明細與未驗證項見manifest.regression_matrix；原正式證據Gate必須先通過，不以跳過案例取得合格。Tesseract及OCR模型未隨包提供，WindowsOCR能力待本機條件驗證。

Windows測試包明確啟用UTF-8，避免系統傳統編碼使中文來源快取失效。固定版打包器的啟動選項已在真實EXE原設定／UTF-8對照中驗證，原快取與正式輸出Gate保持有效。
