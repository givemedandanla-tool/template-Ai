# 已安裝 Illustrator 時的本機原生讀取提案

狀態：PROPOSED_NOT_IMPLEMENTED。使用者詢問「如果說我有安裝illustrator，情況會不會更好？」。已說明原生.ai讀取有優勢，但目前template_ai沒有Illustrator／COM／JSX串接；僅安裝不會改變正在驗證的EXE。此提案不新增已完成父題、不變更目前候選、不聲稱已通過真實本機驗收。

## 建議分工

若使用者已持有可用合法安裝，優先透過本機腳本取原生資料，交給既有學習核心；沒有Illustrator或某物件無法讀取時用Inkscape與PDF相容內容，再以OCR／本機字型比對補救。沿用既有授權，不啟用新API、雲端模型或作品上傳。Illustrator本身授權／自動字型服務的網路行為需在使用者環境核對，不能憑本機腳本就宣稱Adobe全部程序永不聯網。

| 原生讀取有助取得 | 仍須保留的判讀與驗證 |
| --- | --- |
| 可編輯文字、字型名稱、字級、horizontalScale、tracking、段落對齊等腳本可見屬性 | 按實際字串區段保留混合樣式；來源字級、物件變換與有效外觀分開，不以單一值覆蓋混合文字 |
| 文字框、物件／群組、圖層、畫板、可見／幾何界線 | 座標／單位與變換矩陣正規化；畫板不等於作品，同畫板多作品及同人／多人／公司共享仍依既有契約 |
| 原應用匯出的比對PDF／SVG | 保留原稿hash與派生版本、視覺核對、缺字／字型替代及裁切效果；原生DOM不等於全部私有功能均可解析 |
| 原生物件識別與註記線索 | 只在來源hash及適配器版本下映射既有stable ID；隨筆與資料語意仍待核對，不把原生物件ID當跨版本永久同一性 |

已轉外框的文字通常只剩向量形狀；安裝Illustrator不會自動還原原文字。來源缺字／替代字型、外掛物件、未暴露效果與無法核對值維持UNKNOWN。姓名、電話、職稱等語意、欄位歸屬、等效交換、家族、條件容量、預設優選及確定性仍由Template AI學習／求解，不是一份.ai直接變一個模板。

## 實作與驗收方向

1. 先做本機能力探測及版本紀錄；採官方支援的腳本入口，必要時提供手動匯出腳本備援，原稿不覆寫。針對讀取副本使用不保存關閉與前後hash核對，避免干擾使用者既有文件。
2. 保留觀測管道、原始值／座標、可核對狀態、適配器／應用版本與來源映射；走同一來源／審查／學習契約，不繞過舊稿或已確認稿版本保護。
3. 合成含混合字型、分散對齊、縮放、旋轉、群組／裁切、多人／多作品、轉外框及缺字的.ai／腳本案例；無Illustrator環境先驗證資料契約，真實腳本執行必須在有應用的Windows實機另驗，不能把mock當原生PASS。
4. 全程保留本機作品／字型／模型；沿既有安全診斷匯出工具版本、缺少資料類別與錯誤摘要，不擴張原文蒐集或要求上傳私人作品。
