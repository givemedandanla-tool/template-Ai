# 作品判讀與核對工具：第一次使用

1. 下載 **TemplateAIReview-v0.1.0-beta.1-windows-x64.zip**，完整解壓到可寫入的本機資料夾。不要只取走EXE。
2. 執行 **TemplateAIReview.exe**。程式會顯示開啟狀態；私人資料保存於本機獨立工具資料夾，不變更舊版資料庫。
3. 先加入一份作品，按「開始判讀」。觀察原稿與畫面提示，確認作品範圍是否找齊、框對。
4. 點原稿上的標記，核對文字、資料種類、人物公司歸屬與共享。錯誤可修正；未知可保留，不必猜答案。
5. 需要技術資料時開啟「查看全部判讀資料」，點數據定位原稿。數字與原稿範圍相互對應，日常表單不堆精確參數。
6. 做到一半按「保存進度」；檢查完按「完成這份核對」。重新開啟後確認記錄仍在。
7. 遇到問題，用「匯出問題報告」先看內容，再手動提供給Codex。不要上傳私人原稿、字型或完整資料庫。

## 內附與選配

- 已附必要Python／Qt執行環境及經校驗的Inkscape，不需另外安裝這兩項。
- 已附官方固定英文／繁體中文OCR模型；**Tesseract OCR執行器仍為選配，這個版本沒有內嵌**。沒有引擎時仍可讀原有文字、框選和人工修正，畫面會明確提示。
- 字型使用你本機已有字型；猜測或相似字型保持候選，不當成原稿已確認。
- 不連線上傳作品或自動下載字型／模型；正常使用離線。
- 按鈕使用固定版本的 Lucide 單線圖標，隨包保留 ISC 授權及來源清單，位於 `_internal/template_ai/review_tool/icons/`。

## 這個版本的用途

這是先驗證判讀與人工核對流程的獨立工具。保存或核對完成不代表AI已訓練、模板已產出或正式印刷資格通過。原生AI私有結構、外框文字、混合字型等可能需要人工補標。先從資料副本小批測試，再增加數量。

本版尚無Windows程式簽章；若系統阻擋，先核對下載來源、版本與SHA256並回報，勿以關閉防護作為操作要求。

Inkscape對應原始碼與授權由Release的SOURCE_DOWNLOADS.json列出，供授權／開發用途，日常操作不需要另外解壓來源附件。
