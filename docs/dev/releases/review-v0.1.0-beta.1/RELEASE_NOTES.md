# 作品判讀與核對工具 0.1.0-beta.1

第一個獨立Windows實測版，用於確認系統如何判讀作品，以及人工標記／修正／保存的流程。採原稿中心工作台與步驟引導；一般面板聚焦可見內容與歸屬，技術資料透過總覽定位原稿。

請下載程式ZIP並**完整解壓後執行TemplateAIReview.exe**，不需另裝Python或Inkscape。請先用一份資料副本測試保存及重開。

## 下載附件

- 程式ZIP：完整可攜資料夾。
- release-manifest.json：精確來源、全部包內檔案hash、驗證範圍與已知限制。
- SHA256SUMS.txt：下載校驗。
- validation-summary.json：本版Windows／真正EXE的實際結果，與私人作品驗收分開。
- SOURCE_DOWNLOADS.json：內附Inkscape的相應開源來源下載位置及hash；日常操作不需解壓原始碼。

## 重要界線

這是判讀與核對工具，尚不是後續AI學習／歸納模板或完整排版軟體。任意原生AI還原、真實私人作品品質、本機全部字庫、使用者硬體與新手可用性需本機回饋；未確定的字型、間距或結構明示未知，不以預設值補成真值。

**已附官方中／英文OCR模型，但Tesseract執行器選配，未隨包內嵌。** 缺少OCR時仍可使用原文／向量與人工標記路線。私人作品、客戶文字、字型及資料庫留本機，正常使用離線；報告由使用者查看後手動分享。

獨立本機資料目錄，不自動遷移舊版資料庫，不覆寫舊版EXE或已確認稿。此測試版未簽章。公開後狀態為「已發布，待使用者本機確認」。
