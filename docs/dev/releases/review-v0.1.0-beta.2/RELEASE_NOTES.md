# 作品判讀與核對工具 0.1.0-beta.2

本版加入隨包附帶的Tesseract OCR執行器，搭配固定英文／繁體中文模型。完整解壓後即可本機離線辨識，不必另外安裝Tesseract或Inkscape。

下載TemplateAIReview-v0.1.0-beta.2-windows-x64.zip，完整解壓，進TemplateAIReview資料夾執行TemplateAIReview.exe。加入一份作品→開始判讀→核對／修正→選核對狀態→套用修正→保存進度。報告在「更多→匯出問題報告」。

包內OCR優先且核對版本與檔案完整性，不默默換成電腦中其他引擎。缺檔／損壞會提示問題，可人工補標；不確定的字型、文字及歸屬保留未知，不能把OCR候選當人工已確認。

舊判讀核對記錄仍可讀；新固定OCR的判讀版本另外記錄，保留人工修正，不默默合併舊判讀。

這仍是判讀與人工核對工具，不包含後續AI訓練或模板產出。私人作品、字型與資料庫留本機；舊版檔案與資料不自動遷移。本測試版未簽章，遇系統阻擋請核對來源／SHA並回報，不需要關閉防護。

## 附件

程式ZIP、release-manifest.json（來源與逐檔hash）、SHA256SUMS.txt、validation-summary.json、SOURCE_DOWNLOADS.json。開源元件授權／來源記錄隨包保存；來源附件供授權與開發用途，日常操作不用另外解壓。

本版發布前須通過相關Windows來源回歸、實際EXE包內英文與繁中OCR／人工退路／保存重開，以及草稿與公開兩次下載校驗。實際結果以驗證附件為準，不宣稱真私人作品或全部硬體已合格。
