# v0.2.0-beta.1 Windows x64 實測交付

使用者於2026-10-21明確要求「在github發佈程式本體exe，讓我投入實機測試」。本次授權取代先前EXE延後，僅限這次內部測試版；不合併main，不實作教學／知識庫草案。沿用RELEASE_MAINTENANCE_POLICY.md，既有CORE-090操作與資料規則不得退化，原外部資格及需求完成數不變。

修改前驗收／預計測試：
- 統一單一版本來源、包名／UI／報告／manifest，固定來源提交。
- 修正frozen子程序與備份副本重新啟動，僅允許已存在的內部模組。程序協定、離線與來源規則不放寬。
- Windows原生程序隔離回歸；從實際打包EXE執行合成輸入／產稿／預覽／拖動／更正／確認／允許輸出／報告／保存與重啟檢查。
- 包內排除私人資料、字型、模型、開發檢查工具；保留必要產品來源hash及合法授權。
- 建立Pre-release、上傳、實際下載校驗與不可變來源證據；失敗不標已發佈。

Checkpoint：每個可恢復里程碑／10分鐘保存狀態與Git提交，精確遠端讀回後標REMOTE_VERIFIED。Git讀寫可用；目前本機api.github.com被平台網路政策擋住，必要網路草稿已保存、未生效。可使用這次精確tag的明確發佈請求啟動既有GitHub標準Windows runner，由工作流程使用內建GITHUB_TOKEN發佈與下載核對，再以專用證據分支保存結果；不啟用一般push打包或新付費服務。

真實作品品質、使用者Windows硬體效能、實體印刷、獨立新手資格仍未驗證。此交付為beta，不宣稱正式生產合格。
