# Template AI v0.2.0-beta.2 — 隨包 Inkscape 實測版

請下載 TemplateAI-v0.2.0-beta.2-windows-x64.zip，完整解壓後執行 TemplateAI/TemplateAI.exe；不可只拖出 EXE。不需另裝 Inkscape，程式固定使用包內 1.4.2。個人字型仍須在電腦上合法安裝。

本版修正向量匯入的工具選擇、工具版本快取與安全報告；保留舊資料及已確認稿的來源／版本檢查。包內元件遺失或受損會阻擋向量匯入並提供重新解壓指引，不偷偷換用系統版本。Illustrator 自動化及私人格式完全還原未包含。

首次測試請用獨立資料副本，保留原稿，不直接操作唯一的正式資料庫。作品、字型、模型及資料庫留在本機；軟體不自動上傳。需協助時由你匯出安全問題報告，再交回 Codex。

另外的 inkscape-1.4.2-corresponding-sources.zip 是開源授權所附的對應來源，日常使用不需下載。SHA256SUMS.txt 與 release-manifest.json 可核對來源提交、全部包內檔案及實際測試。

此版未簽署，Windows 可能顯示發行者不明；請核對此專案 Release 與雜湊。合成案例驗證不等於私人作品訓練品質、使用者電腦效能、實體印刷或完整斷網隔離資格。
