# 本機問題回報：軟體不會自動傳送資料

使用期間，Template AI 在本機分析、學習、排版與保存。沒有自動上傳、遙測、雲端 AI 或更新下載。開發環境準備工具／安裝依賴，與成品的日常使用分開。

## 遇到問題時

1. 保留當前資料，在主畫面按「問題與報告」。
2. 選「當時在做什麼」。若畫面提到缺少來源、字型、OCR、模型或其他資訊，可在旁邊選擇；不確定也可以。
3. 按「記下這個問題」，閱讀「發生什麼／影響什麼／接下來怎麼做／缺少資訊」。
4. 按「匯出問題報告」，選擇可寫入的本機資料夾及新的 ZIP 檔名。取消或保存失敗會保留目前報告；不覆寫以前的報告。
5. 自行把 ZIP 附到 Codex 對話，補充「想完成什麼、做了哪些步驟、預期與實際結果」。軟體不會替你傳送。

「顯示技術資料」提供專業人員可讀的完整 JSON。也能開啟以前的報告；程式會重新驗證並由安全資料重建畫面，不執行報告內的程式或載入私人附件。

若要分析特定稿件的幾何、欄位與輸出資格，可另外保存既有「這份稿件的問題／檢查報告」。本機使用報告記錄軟體運作，不會取代稿件檢查或放行正式輸出。

## 主畫面無法啟動時

在下載程式的資料夾，用同一個資料目錄執行：

```powershell
.\.venv\Scripts\python.exe app.py --data-dir C:\TemplateAI-Data --support-report C:\TemplateAI-Reports\report-001.zip
```

Linux 開發環境的對應指令：

```bash
.venv/bin/python app.py --data-dir /tmp/template-ai-data --support-report /tmp/report-001.zip
```

目的資料夾要先存在，檔名須尚未使用。這個入口不需要開 Qt 主視窗；即使 Qt 等第三方套件缺少，仍可用 Python 標準函式庫匯出報告。Python 本身及程式檔仍必須存在。請使用原本啟動時的資料目錄，才能找到原使用紀錄。

若主程式發生原生崩潰，來不及寫下完整原因，報告只會顯示最後已保存的階段及「上次使用未記錄正常結束」；這不等於已證明崩潰原因。Qt 的提示／嚴重／致命訊息只記等級；致命錯誤仍由 Qt 結束程序。

## 報告包含與省略的資訊

- 包含固定的操作階段及問題代碼、時間、已取得的錯誤類型、可信程式模組／函式／行號、明確記錄的耗時及當時程序記憶體。
- 包含程式版本、可信程式檔指紋、作業系統類別、套件版本、CPU 數量與實體記憶體總量；沒有主機名稱、使用者名稱、裝置序號或字型清單。
- 不包含輸入原文、客戶資料、原圖、原稿、來源雜湊、字型檔、資料庫、檔案路徑、原始例外訊息、來源程式行內容、區域變數或畫面錄影。
- 訊息自動分類出的「需核對資訊」只是除錯線索；不是證明該資源缺少。`NONE` 表示該項未取得／未標記，不代表合格。
- 最近操作紀錄最多 320 筆；較早紀錄會被有界替換並計數。報告封裝限制 1 MiB。這是除錯預算，不是作品、字串或學習容量上限。
- 耗時欄位未量測時為空值；記憶體是本 Python 程序的當時 RSS，不能當成整台電腦、GPU、子程序或峰值效能驗收。

本機紀錄放在所選資料目錄的 `local-support/recent-operations.json`。無法寫入時，問題畫面會說明，仍可立即手動匯出記憶體中的報告。正常重啟會延續已驗證的有界紀錄；損壞內容不會直接複製到共享報告。

ZIP 只有 `support.html`、`support.json`、`manifest.json`；完整性檢查是 SHA-256，不是作者簽章。沒有模型生產資格、字型安裝資格或印刷合格宣稱。

## 離線範圍

正式 `app.py` 啟動時阻止 Python 的 IPv4／IPv6 socket、DNS、UNC／遠端 URI 路徑；AF_UNIX 保留給本機 Qt/X11/IPC。獨立 Python 核對子程序也啟用防護。開發工具及 Codex 的網路不受成品進程設定影響。

SVG 在交給本機轉換器或原生渲染器前，會拒絕遠端資源、外部樣式與未核對的向量子文件。可使用內嵌資源或已核對二進位格式的本機點陣圖片／字型；需要內嵌時會明確提示，不能默默連網補資料。

本機 Inkscape、OCR、系統字型檢視器及明確開啟的系統檔案檢視器，是獨立原生程式。Python audit guard 不是整個作業系統的防火牆，不替其他軟體、同步磁碟或系統服務宣稱網路隔離。需要整台電腦完全無網路時，可在本地停用網路介面後使用；Template AI 不依賴網路完成既有工作。此項不冒充真實 Windows、外部程式或整機效能驗收。

後續修正流程：收到手動報告 → 根據固定代碼與版本定位 → 建立不含私人資料的重現案例 → 修正與回歸 → GitHub checkpoint → 提供更新。實際作品與字型繼續留在你的電腦。
