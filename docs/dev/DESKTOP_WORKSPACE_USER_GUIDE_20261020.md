# 桌面工作台操作指南

日常使用不連網；取得與首次準備依[本機快速開始](LOCAL_DESKTOP_QUICK_START.md)。
主程式預設開啟「排版與輸出」。資料、原稿、字型與資料庫都留在自己的電腦。

## 第一次試做

空白資料庫尚無版面。先到「模板與圖片」加入合成示範模板試做，或到「匯入與學習」準備自己的作品。
示範與預覽不代表真實作品、正式模型或印刷資格已通過。

1. 在「排版與輸出」設定成品寬度與高度。
2. 按「填寫人物與公司資料」，新增或修改人物、公司、共用聯絡資料與公司圖片。
   按採用後才帶回製作；共享資料的變動仍會要求核對影響。
3. 按「產生稿件」。已啟用的學習規則與固定舊版面各走原本的核心，不會擅自更換已確認版本。
4. 檢查完整預覽；要改內容再按資料按鈕，要改位置按「修改位置」。
5. 依目前主動作確認稿件，再保存預覽稿；正式輸出另須通過原有檢查。

熟悉表格的同仁可展開「使用表格輸入」。表格、人物卡片與舊客戶預填共用同一份製作資料。
進度未完成時可停止；資料仍保留。修改內容或位置後，舊確認失效，需要更新稿件。

## 調整位置

學習稿可拖動藍框內的聯絡資料，表達兩項資料的相對位置。
也可展開「用選單調整位置」，選要移動的資料、參考資料與左／右／上／下。
拖動與選單走同一核心；復原／重做針對位置，不會把更正過的電話改回去。

核心保護不受影響的相對關係，並依規則決定必要的欄位尺寸與文字配置。
不提供客戶任意調整字級、字寬或單雙排控制。
固定舊模板的位置修改仍沿用原有候選編輯工具，不冒稱它已變成新學習家族。

## 其他版面與接續

- 「查看其他固定版面」：展開固定模板候選與待核對原因。收合只隱藏畫面，不改候選的可檢查狀態。
- 「更多稿件選項」：學習稿可查看其他候選、明確採用變更的版面、核對正式資格或開啟已保存的相同檔案。
- 「接續已保存稿件」：帶回該稿的資料、尺寸與排版決定；不把另一稿的舊預覽當成目前結果。
- 「找舊客戶／重訂」：沿用既有客戶與已確認版本，不因新模型默默重排。

相同資料、規則版本與操作意圖有穩定預設。若需要更換版面，會要求明確採用；預設不覆蓋你的決定。

## 匯入、模板與專業操作

「匯入與學習」以匯入作品、自動分析、核對與學習引導為主要入口。
同一來源檔可以包含多件作品。手動框選、來源修復及原有工具保留在「更多原稿工具」。
選取需要修正的欄位時會展開編輯工具；一般製作可維持收合。

「模板與圖片」沿用原目錄、搜尋、比較及家族工具。
「更多工具」與上方分類選單保留原有功能；畫面簡化不刪除專業工具。

「工作引導」提供四步：核對作品、準備驗證案例、檢查適合範圍、審查正式啟用。
案例可保存、驗證可暫停接續。缺少來源或資格時會說明原因，勾選框不會把合成測試變成正式證書。

## 遇到問題

到「問題與報告」先看白話摘要，再展開技術資料；選擇當時的階段及需要協助的項目後，手動匯出 ZIP。
軟體不會傳送資料。你自行把安全報告附到 Codex，並描述原本想做什麼及出錯前幾步。
詳細格式及主畫面打不開時的匯出命令見[離線問題回報指南](OFFLINE_SUPPORT_USER_GUIDE_20261020.md)。

報告記錄程式指紋、依賴版本、固定錯誤分類、可取得的程式位置及有界資源／耗時資訊；不附私人原稿、字型或資料庫。
本輪軟體驗證與 Windows、私人作品品質、真人新手使用及實體印刷驗收分開記錄。
