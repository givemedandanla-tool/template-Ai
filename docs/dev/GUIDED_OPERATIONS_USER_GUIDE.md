# 本機進階工作引導

這個引導把既有來源、學習、容量與正式資格服務接在同一條操作流程。
私人案例、待辦草稿及結果只保存在目前本機資料庫。沒有網路請求，
沒有另一套模型或資格資料庫，也不會把合成測試變成生產證書。

## 1 核對作品

「核對作品與字型」「建立或接續學習」「檢查模板群與共用規則」
開啟既有正式工具的對應頁。可以沿用已完成的家族與16項專業編輯能力。
關閉工具後會重新讀取狀態；有背景工作時先完成或暫停。

## 2 準備驗證

1. 填寫核對人員，選擇要檢查的規則版本。
2. 選用途：「驗證集合」用於學習適合範圍；「封存保留集合」用於獨立檢查。
3. 選擇對應的獨立作品與資料來源。自製／合成測試是預設來源。
4. 設定實際尺寸，填寫來源與輸入相對應的核對依據。
5. 用既有人物卡片視窗填寫案例資料，再加入待驗證清單。
   這份資料不會更改主製作區的客戶輸入。
6. 逐一核對後勾選確認，按「保存並開始驗證」。

待驗證案例可關閉重開接續；核准勾選不會保存或自動勾選。
一批只承接同一規則版本及同一用途，訓練集合不出現在獨立作品選項。
背景工作逐項保存，可完成目前案例後暫停，再從已保存處接續。
關閉正在處理的引導時，會先暫停並保存，避免直接銷毀工作執行緒。

案例對應與來源類別必須反映實際本機情況；介面勾選不能證明真實性。

## 3 學習適合範圍

選已完成的驗證工作，逐份查看真正的排版預覽，決定是否符合合格作品風格，
並保存核對依據。核對結果與精確稿件摘要綁定，不能直接覆寫。

接著審查獨立組數、成功率下界、單側錯誤機率及聯合需求分組寬度，
確認後建立適合範圍。預填值只是統計起點，需要操作者核對，
不是自動學得的字數限制、欄位上限或印刷精度。

介面呼叫 `LocalCapacityCalibration.review_case/from_evaluation`，
不使用 TRAIN 或封存 HOLDOUT 擬合範圍。
不足證據的區域仍不合格或未知；可能保存一份「0個合格區域」的結果。
它不等於所有輸入都不合法，也不取得正式模型資格。

## 4 審查正式啟用

選已完成的封存工作，對照新規則稿與基準稿，逐份保存比較及實際依據。
缺少任何一份實際稿件時，核心拒絕美感比較。
同一稿件已有比較時不重複建立衝突證據，可另建獨立驗證工作重審。

本機真實授權作品還需要來源及近似重複／獨立性審查、明確門檻與完整證據。
「檢查並保存資格」呼叫 `DesignQualification.plan/approve`，
「啟用已通過資格的規則」另行呼叫 `validate_certificate` 與既有啟用服務。
來源、字型、比例、獨立性、逐稿比較或版本有缺項時，維持阻擋並保留原資料。

自製／合成工作即使勾選全部核對，也會被核心拒絕真實來源資格。
已保存資格仍需另按啟用；任何新規則都不默默改寫舊定稿。
資格範圍僅限已有證據的數位排版，不代表實體印刷或未測設備已合格。

## 實作入口及自我驗證

入口類別是 `template_ai.guided_operations.GuidedOperationsDialog(owner)`，
owner為正式主視窗；使用同一 `Library` 與 `TrainingStore`。
測試 `tests/test_guided_operations.py` 直接建立正式 MainWindow，
涵蓋人物卡片接線、來源及家族深連結、草稿重開、實際背景驗證、暫停接續、
實際稿預覽、風格核對、容量API、用途分離、錯誤保留與合成資料拒絕正式資格。

合成軟體自我驗證不能當作真實作品學習品質或真人新手可用性結果。
