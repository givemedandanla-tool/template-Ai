# 按鈕與狀態草案

2026-10-23：配合 B 工作台＋C 引導。功能名稱及效果為討論草案，未經新工具實作／實機驗證。版面只呈現目前需要的工具，詳細數值移入總覽。

## 主要流程

| 按鈕 | 圖標概念 | 點擊效果 |
|---|---|---|
| 加入檔案 | 資料夾加號 | 多選 AI，建立清單及預覽，顯示讀取階段／失敗；不冒稱詳細分析完成。 |
| 開始判讀 | 文件掃描線 | 明示本次待判讀數量，再處理尚未判讀項目，顯示目前檔案／階段／完成數。 |
| 保存進度 | 儲存符號 | 保存本次人工標記、修正與核對進度，顯示時間；不授予核對完成資格。 |
| 完成這份核對 | 文件勾號 | 保存目前作品並記錄本輪人審，明列保留未知，提供下一份入口。 |

## 查看與定位

| 按鈕 | 效果 |
|---|---|
| 選取 | 原稿標記與右側資料雙向選取。 |
| 顯示／隱藏判讀標記 | 切換疊圖／乾淨原稿。 |
| 看整份作品 | 回到完整作品範圍，不改實體尺寸。 |
| 放大／縮小 | 只改觀看倍率，可配合滑鼠與鍵盤。 |
| 下一處待核對 | 定位尚未核對或未知項目，同步顯示資料。 |
| 上一份／下一份作品 | 同檔或跨檔逐份查看；未保存變更先處理，不能無提示丟棄。 |
| 查看全部判讀資料 | 開啟右側總覽，保留中央原稿；按物件／關係搜尋、篩選與展開。 |
| 定位到原稿 | 把目前資料引用的對象移入可視範圍。 |
| 放大檢查 | 明確放大至適合查看選取對象。 |

總覽中點選尺寸／間距／切齊／基線／分散／群組／歸屬，依 DESIGN.md 顯示對應視覺標記。「看整份作品」沿用同一個功能，避免重複入口。

## 選取後的標記工具

| 按鈕 | 效果 |
|---|---|
| 新增標記 | 先選作品、文字、圖片／Logo或旁註，再框選漏判內容。 |
| 調整標記範圍 | 拖動邊界修正範圍；改判讀記錄，不移動原稿物件。 |
| 標記彼此關係 | 多選後以白話選項標記群組、對齊與排列。 |
| 移除這個標記 | 只移除判讀標記，保留原稿。 |
| 復原上一步 | 撤回人工修改，保留可追溯修訂。 |
| 比對本機字型 | 顯示原稿與候選的視覺比較；不將候選自動當確認答案。 |

一般右側表單直接編輯文字、資料種類、人物／公司、共享、旁註分類與核對狀態。肉眼可見範圍與關係以視覺操作處理；pt／ScaleX／座標等數字不放日常表單。是否在專家總覽中允許技術值修改仍待討論。

## 依狀態出現

| 按鈕 | 出現條件與效果 |
|---|---|
| 暫停／繼續 | 處理中可要求安全暫停；先顯示正在暫停，實際到邊界保存後才稱已暫停。 |
| 重試失敗檔案 | 只重試失敗，保留成功與人工資料。 |
| 接續上次工作 | 重開後恢復來源、標記、修正與進度；背景是否自動續跑另待確認。 |
| 重新判讀 | 更多選單內建立新判讀版本，保留人工修正並顯示差異。 |
| 匯出問題報告 | 白話摘要＋技術詳情，可先看內容，預設排除原稿、客戶文字與私人檔案，不自動上傳。 |

## 狀態語意

檔案已加入／可預覽、判讀中、已判讀待核對、人工已修正未保存、已保存、已核對但仍有未知、已核對無待查項、部分失敗、缺少配套、正在暫停、已暫停及恢復中必須可區分。

這些狀態不等於模型訓練或模板／正式輸出資格。未知、未執行、逾時與已證明不適用不可合併成失敗或無解。任何受影響的隱藏數據問題仍需白話提示。

未決：最終按鈕位置、尺寸／縮放基準、檔案與作品清單結構、數據總覽寬度、搜尋行為、快捷鍵及技術值修改政策。不得用概念圖自行補成核准規格。
