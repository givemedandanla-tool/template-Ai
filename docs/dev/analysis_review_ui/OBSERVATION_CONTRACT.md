# 作品觀察資料與判讀能力契約

2026-10-23。用途：第一部件保存可追溯觀察，供下一個「AI 學習與歸納產出模板」部件使用。此為必需資料種類及驗收要求，不表示現有程式已自動取得每個值。

## 1. 必需核心與邊界

| 核心 | 配套／既有起點 | 交付要求 |
|---|---|---|
| 檔案辨識／來源 | importer、內容hash、來源store | 識別實際格式、版本與頁，不改原稿。 |
| AI轉換／查詢 | 包內Inkscape | 外觀／語意雙管道；新工具驗真實包內呼叫，任意AI私有結構不保證完整。 |
| 原文字與結構 | pypdf、pdfminer.six、SVG解析 | 原始與衍生資訊分清，保存可定位來源。 |
| 預覽／外觀核對 | Qt PDF/SVG、墨跡與位置比較 | 發現缺字／移位／外觀衝突；外觀成功不等於結構完整。 |
| OCR | Tesseract＋eng/chi_tra模型 | 本機辨識文字與位置；目前可選配，不能稱現有EXE已隨包。新工具交付需驗引擎／語言模型及缺失路線。 |
| 字型索引／量測 | fontTools、Qt shaping | 實際字型檔／face／缺字／替代；正向量測不等於逆向參數唯一可辨識。 |
| 字型反查 | local_font_recovery、visual_font_match | 真實候選渲染比較，歧義／未搜完保留未知。 |
| 多作品／尺寸 | source_analysis、source_region_hypotheses | 群組／幾何／尺寸文字／留白共同提候選，無框及衝突需可人工修正。 |
| 語意／歸屬 | phonenumbers、規則與本地分類、穩定ID | 類型、角色、人物公司、共享、標籤／圖示對應，不能按同字串合併。 |
| 結構／幾何關係 | observation、networkx與幾何統計 | 完整關係輸出尚須補齊，不以有限dx/dy當完整對齊分析。 |
| 人審／持久化 | 新UI、SQLite、版本化交換清單 | 原判讀與修正並存、復原、保存重開、雙向定位。 |
| 工作／診斷 | runtime queue／worker、安全報告 | 可信進度、有限預算、暫停接續；首檔安全逾時已知缺口尚未修妥。 |

已有程式入口、支持條件可執行、真實Windows／私人作品驗收是三種不同資格。不得僅列工具名就稱能力已驗收。不要求上傳私人作品，不新增收費模型API。

| 字型 | 宣告與實際字型分開、檔案hash、face/style、必要的變體軸、替代／缺字、候選與搜尋完整性。 |

| 切齊 | 參與物件、左／右／中／頂／底／基線、目標錨點、參考線、實際殘差／容差及依據。 |
| 分散 | 作用單位與數量、單位位置、原生advance、額外gap、目標跨度、首末錨點／邊界、末行／單單位實際處理、共同切齊。不可用Unicode碼點數代替塑形單位。 |
| 相對幾何 | dx/dy、邊界gap、基線距離、欄列／閱讀序、鄰接、順序及比例，帶選鄰策略版本與量測端點。 |
| 群組 | 原生／推估父子、共同容器、範圍、成員及閱讀／排列結構。群組範圍不等於另一個印刷物件。 |
| 資產／權利 | 字型／Logo／圖形依賴hash及適用核准；Logo公司＋實體尺寸＋核准版本。私有檔留本地，不因交換清單就任意散布字型。 |
| 品質／修訂 | 全件合格與局部噪聲分開、原判讀／候選／人工答案、修訂ID與時間／理由、未執行／部分完成／預算截斷／來源衝突。 |
| 跨作品線索 | 角色／群組／版本／尺寸的對應候選、匹配依據與歧義；客戶ID／人名不作風格捷徑，保持lineage供後續分組驗證。 |

圖關係至少能表示 contains、renders_fact、label_of、icon_for、owned_by、shares_reference、aligned_to、baseline_with、precedes、gap_to、relative_to，以及人物公司與共同容器。每條關係有有效端點及證據。

## 3. 每值共同欄位

單位、座標基準、來源管道／位置引用、取得方法、狀態、依賴與演算法版本、候選／分數語意、未知／衝突原因、人工修訂。直接取得、推算、推估與人工標記不得混為原稿事實；衍生SVG的宣告不能自動當原生AI真值。缺值不是零，未知字型／pt不補預設，未校準分數不稱機率。

非等比矩陣、外框文字或混合runs下，單一物理pt與ScaleX可能無唯一答案，保留矩陣與候選。欄框、墨跡與容器可用寬是不同資料，未知容器不虛構。

交換、省略、重複、容量上限、合適字串區間、縮放聯動、預設優選與合法變換由後續跨作品／政策／驗證歸納；本部件保存觀察、例外及明確人工依據。一次出現／未出現不等於允許／禁止。

## 4. 目前缺口與驗收要求

現有 design_observation 的關係種類主要為 contains/owned_by/observes_role/person_company/derived_relative_geometry；glyph、基線、alignment、distribution、source_container、label/icon binding仍可能UNKNOWN。來源審查能補部分typography，不代表任意AI可自動完整反查。這份契約不提升舊功能完成數或外部資格。

必須驗：真包內引擎及本地OCR呼叫／缺配套退路；已知真值尺寸與文字樣式；無框多作品／旁註／多人共享／混合與外框文字；不可辨識案例保持未知；資料到原稿雙向定位；修正保存重開／重新判讀不覆蓋；觀察包有效引用、版本、單位及完整性；長工作進度／安全暫停與恢復。合成資料通過不冒充實際Windows／私人AI／本機全部字庫／學習品質資格。

大量數據分頁／按需讀取，保留完整性與截斷狀態；交換清單以版本化結構及本地資產引用保存，可追溯原稿。安全分享報告是另一份白名單輸出，不等於含私有文字的完整觀察資料包。
