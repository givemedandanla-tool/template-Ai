# 作品判讀與核對工具：UI 設計基準

狀態：**設計原則已確認；按鈕為待逐畫面核對的草案；尚未實作新工具。**
決策日期：2026-10-23。使用者最新指令為「保存到 GitHub 後開始討論實機 UI」；前一句「實機 AI」已由後一句更正，不啟動模型訓練。

## 1. 目標、順序與交付邊界

使用者因既有軟體難以理解下一步、實際操作問題頻繁，要求重新以 UI 定義工作流程，分為：

1. 檔案分析與模板產出。
2. 模板編輯。
3. 輸入資料與模板調用暨預覽。

第一部分先收斂為最小「作品判讀與核對」工具：讀入作品 → 查看判讀 → 標記錯誤或缺漏 → 修正 → 保存 → 重開核對。確認這個部件可靠後，再推進 AI 學習、歸納與模板產出。既定跨作品學習目標不變，不以一作品一模板為最終產品。

本工具沿用同一個 template-Ai 倉庫的開發脈絡，規劃獨立入口與未來獨立下載交付；本次僅保存設計，不修改產品、打包、發布新版本或合併 main。網頁與手機仍延後。

## 2. 已確認的面板與視覺方向

- **B 的原稿中心工作台**：左側檔案／作品清單，中央原稿與判讀疊圖，右側目前選取項目的資料，下方保存狀態。
- **保留 C 的步驟引導**：加入檔案 → 判讀檔案 → 核對與修正 → 保存與完成。保存可隨時進行；步驟不是強迫只能單向行進的精靈。
- 現代、清爽的淺色介面，原稿為主要視覺中心；圖標搭配繁體中文白話名稱，關鍵操作不只靠圖標或滑鼠懸停提示。
- 依狀態呈現工具，階段內突出一個主要動作；狀態同時有文字與圖形，不能只靠顏色。
- 數據、操作、保存結果及下一步須能由介面理解，不依賴聊天教學。

參考方向為 PowerToys／Fluent 的熟悉與清晰、Penpot 的原稿工作區、Label Studio 的核對流程；只採公開的設計原則。候選圖標來源為 Lucide（ISC），本次未安裝或隨產品交付任何新元件。

## 3. 核心規則：簡潔面板與完整資料分層

**日常面板只處理肉眼可見的資訊，以及資訊歸屬關係。其他量測數據由系統保存，預設隱藏，並提供總覽入口。**

日常面板：原稿文字、資料種類、人物／公司歸屬、共享、作品／欄位範圍、圖形或旁註、群組，以及肉眼可判斷的排列／對齊。使用點選、框選、範圍控制點和白話選項，不要求逐筆填寫底層參數。

預設隱藏：精確座標、pt、ScaleX、字距、分散間隙、切齊偏差、矩陣、字形量測與演算法紀錄。需要核對字型外觀時，使用視覺候選比較；數字校正不放進日常表單。

單一入口 **「查看全部判讀資料」**：按作品／欄位查看量測、關係、來源、未知原因及人工修訂，可搜尋與篩選，按需展開／分頁讀取，不能一次展開全部大型資料。是否開放專家修改數值、如何授權及覆核尚未定案，不能默認允許。

隱藏數據不等於隱藏問題：影響判讀可靠性的缺失仍在主面板用白話提示，例如「這段文字的字型尚未確定」。

## 4. 總覽與原稿的雙向視覺連動

總覽在右側資料區開啟，中央原稿持續可見。點資料選取／定位原稿對象；點原稿則切換到相應資料。第一次開啟總覽跟隨目前選取項目；可切回作品層級。可視化的量測／關係數據項必須具有可解析的物件或關係引用，不能成為無法定位的孤立數字。版本、執行耗時等中繼資料只需有效來源引用，不強行畫框。

| 選取內容 | 原稿視覺化 |
|---|---|
| 欄位寬高 | 框出量測對象，水平與垂直尺寸線，顯示實體單位。 |
| 文字實際占位 | 顯示墨跡範圍，與欄位框／容器用框線及文字區別。 |
| 欄位間距 | 同時框出兩端對象，在實際被量測的邊界間顯示距離線。 |
| 切齊 | 顯示相關欄位、共同左／右／中等參考線及偏差。 |
| 基線 | 顯示文字基線及相對高度差；不能用墨跡底邊冒充基線。 |
| 分散 | 顯示參與單位、兩端錨點及各段間隙，區分原生占位與額外間隙。 |
| 群組 | 框出整組範圍及包含成員。 |
| 歸屬與共享 | 突出相關人物／公司的欄位，附共享標記。 |

一次優先呈現一項選取關係，避免所有線條同時覆蓋原稿。定位時必要才平移，不任意改觀看倍率；「放大檢查」明確放大，「看整份作品」回到全貌。畫面縮放不改作品實體尺寸。

必須明確標示量的是欄位框、文字墨跡或容器。只有墨跡證據時，不能虛構容器。推估使用虛線加文字，未知列出原因，不畫成確定量測。單純查看／定位不修改標記；修改範圍必須明確進入該操作。

## 5. 保存、人工確認與版本

- 原始作品不可變。新增、移除及調整針對判讀標記與記錄；本部件不重新排版原稿。
- 原判讀、推估及人工修正分開保存，具修訂歷史、穩定 ID 和證據引用；重新判讀建立新版本，不覆蓋人工記錄。
- 保存進度 ≠ 人工核對完成；人工核對完成可保留明確未知，亦不代表客觀全對、已訓練、模板可用或正式輸出合格。
- 作品事實、家族共用規則、單次稿件／確認稿、模型與評估分層版本保護。單件觀察不直接授予交換、省略或縮放權限。
- 私人原稿、客戶資料、字型、資料庫、人工標記及模型留本地。正常操作離線，安全報告由使用者預覽並手動匯出，不自動上傳。

## 7. 下一步實機 UI 討論

先逐畫面核對：首次開啟／接續、加入檔案、判讀中／暫停／失敗、作品核對、總覽視覺化、保存與重開。討論視窗基準及縮放、同檔多作品的清單、可見按鈕、操作結果與下一步。這些細節尚未選定，按鈕草案可依核對調整。

當使用者能獨立完成一輪核對、指出錯誤、修正並重開讀回，且畫面與實作一致，才能驗收最小核對部件。真實 Windows／私人 AI／全部本機字庫與後續模型品質仍各自依實機證據驗收。
