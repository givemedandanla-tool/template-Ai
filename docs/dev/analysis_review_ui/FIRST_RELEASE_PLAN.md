## 實作與驗收

1. session原子保存／備份恢復、穩定ID、人工資料不被重判讀覆蓋及安全匯出。
2. 真Inkscape／原文字／可選本機OCR、多頁與多作品、階段progress及有界逾時；缺配套可人工核對。
3. 真Qt原稿Canvas映射、選取／框選／調整／復原、關係與測量定位、保存重開。
4. 真Windows原生EXE開啟／worker／操作閉環及來源hash不變，不能用Linux截圖替代。
5. 固定相依、包內Inkscape及授權來源附件、OCR可攜包若無可確認來源則如實列選配；不得假稱全部內嵌。
6. GitHub新Pre-release、固定來源／manifest／SHA256、草稿附件及公開後真下載核對。
