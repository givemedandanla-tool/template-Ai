# CORE-026／027：受控批次來源恢復

2026-10-14（Asia/Taipei）；依 UI_DECISIONS.md 的 UI-049 全文及既有 SOURCE_RELINK_DESIGN.md。參考來源沿用已閱讀的 InDesign Links、Blender bpath 與 DVC hashfile；採用工作流及串流內容識別思路，自行實作。使用 hash table 以 (SHA-256, bytes) 分組，搜尋期每候選檔只讀一次，不按來源登錄重讀；多來源仍保持獨立 id。搜尋的時間 O(目錄項數＋符合長度檔案的總 bytes)，記憶體 O(已登錄來源＋受限候選)，緩衝 1 MiB。相同 bytes 的不同實體副本也必須逐檔讀取，不能在未讀取時宣稱內容去重。

## CORE-026：背景搜尋与候選預覽

只掃描使用者選取的一個本機根目錄及其子目錄；不預設整台電腦、跟隨符號連結或跨檔案系統。預設最多 5000 個目錄項、256 MiB 候選讀取總預算、單檔 200 MB、目錄深度 32、每來源最多 32 個候選、來源上限 2000；取消於目錄項及讀取 chunk 間生效。達預算或取消則明示 PARTIAL／CANCELLED，並區分無權讀取、同名異內容、未知指紋、多個相同內容副本及沒有候選。不得把搜尋未完成當全範圍未找到。

舊內容表 bytes 讀出到來源快照，不寫原登錄；背景無 SQLite 存取。候選顯示原登錄／目前位置、hash／長度、來源 id、作品與模板／Logo 影響（既有實際引用）、客戶關聯未知。每列預設未勾选、候選預設未選，不依排序或相同內容暗中核准身份。使用者選候選且明列勾选後，確認來源身分與影響，再次背景核對所選檔案，交 GUI 執行緒提交。取消搜尋不得啟動提交。

## CORE-027：批次交易與復原

BEGIN IMMEDIATE 中對全批逐件核對來源 hash、bytes、驗證後 stat、來源位置 revision；全批相容才更新。路徑變更、逐來源歷史、批次 id／項目、確認及事件同 SQLite 交易保存。一筆過期、內容異動、候選消失或事件失敗，全批不更新；不偽稱部分成功。維持每條原登錄、作品與發布模板，不改原檔或衍生快取。

復原是新的一批位置版本，不刪歷史；列出舊位置、再次背景驗內容且核對原批次後的當前 revision，舊位置失聯或內容變更即拒絕，不讓後來重連被旧批復原覆蓋。取消確認不改資料。批次紀錄重開可查。

## 範圍與驗收

合成測試驗證同內容異名獨立登錄、長度預篩／每檔一次 hash、候選歧義、同名異內容、部分／取消／不可讀、符號連結範圍、全批回滾、revision 衝突、正常／失聯復原、歷史重開及 GUI 預設不選／取消不寫。Windows、真實客戶映射、來源內容替換、字型／跨設備全部依賴搬移、可恢復掃描進度與多搜尋根仍未完成；UI-049 保留 PARTIAL。
