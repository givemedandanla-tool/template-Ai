## 必須保留的訪談結論

- 學習跨作品的共用規則與條件變化，避免一作品一通用模板、每個排列再生一個模板。
- 同一家族內合法交換優先；較大差異再找其他家族。語意、人物／公司歸屬、標籤／圖示、字型、實測容量與周圍關係都要成立，不能只比較框大小。
- 客戶表達必要的相對位置；字級、字寬、欄框、切齊、分散由核心聯動。其他欄位可以依法調整大小，只要需要保護的相對關係仍成立。
- 所有多合法結果有版本化預選與穩定決勝；已確認訂單保留精確輸出檔案，不能因重訓而重新排版。
- 專業後台原有來源標註、字型／幾何編輯可沿用；不得把它們擴充成客戶字級、字寬、單排／雙排或任意數值間距控制。
- 來源事實修正、單次排版偏好、通用規則修訂是不同操作。局部修正不能自動發布全域規則；模型係數不作自由手改。
- 作品、字型、客戶庫、模型與定稿留本地；不新增付費 API 或自動上傳。網頁／手機／EXE 延後。
- 適合區間根據合格風格與獨立驗證得出，樣本最大值不是容量硬上限；UNKNOWN 不由預設值補成真值。

## 數學與演算法設計

1. **家族辨識與近似候選**：沿用結構／字面特徵、缺值遮罩、來源 lineage 去重與 HDBSCAN。外觀相似不等於同一結構；來源身分不用作風格特徵。人工對應修正先更新有版本的觀察／樣本，再產生新模型。
2. **代表案例選取**：先分尺寸、角色組合、獨立來源、常見／低支持模式與問題類型，再在各層挑中心近例與距離較遠的邊界例。可用非負相似度的設施選址目標 `F(S)=Σ_i w_i max_{j∈S} sim(i,j)`，用貪婪邊際增益提出審查集合；獨立來源限權，強制保留少見組及已知失敗。這是待驗證選取啟發，不宣稱全庫美學保證或在額外分層約束下仍具無條件最優界。
3. **合法交換與容器指派**：先核語意、owner、標籤／圖示與政策，刪除非法邊；其餘用 `min Σ c(i,j)x(i,j)`。成本依已支持的預設語意位置／角色、實際文字配置與穩定決勝組成。每個分配仍須檢查雙向承接及整卡布局；不能只把成本最低稱為印刷合格。
4. **相對布局**：在有限候選結構下，以 Kiwi 保持硬性歸屬、完整內容、安全區、不重疊及客戶明確關係；其他關係依既有強度／規則處理。依賴圖確定受影響閉包，僅改必要部分；不是只重驗那兩個被拖動欄位。
5. **文字與欄框聯動**：沿用條件 joint 模型與多風格模式，以實際 shaping 量測檢查。不得獨立拼接各參數最小／最大值，或只看字元數；字串需求在支持域外顯示未支持／預覽，不能自動擴大來源真值。
6. **批次變更與重算**：依賴圖決定樣本→模型／資格→稿件的影響集合，以來源／資產／規則指紋去除不受影響重算。沿用每項 CAS／交易、冪等、進度與可恢復紀錄，不承諾幾千目標單一大交易的全有全無回復。
7. **容量與預選**：沿用獨立 VALIDATION 校準及單側信賴下界；比較完整聯合需求而非單欄獨立區間。學習排序用既有模型；同分以版本化穩定鍵決勝。輸入、尺寸、來源／資產、引擎、模型、政策或有效意圖的相關依賴改變時重算；已定稿重訂優先取原始封存檔。
