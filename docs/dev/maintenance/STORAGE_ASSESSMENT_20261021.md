## 已發現的還原風險

- 226 個 `source.zip` 入口中，**81 個是失效連結**，不能用原本機 ZIP 還原入口。這些項目的歷史提交與收據 tree 均可在本次已核對的 Git 歷史中找到，並不等於歷史程式已遺失；本輪未重建 ZIP、未修復連結，也未聲稱完整還原成功。
- 214 個入口有 REMOTE_VERIFIED 收據，其中 213 個提交可從本次來源祖先追溯。`CP-20261019-JOINT-PARAM-PLAN` 的收據提交不在這次已核對分支的祖先中，需另查分支或遠端物件；**不據此斷言 GitHub 已遺失，也不刪它的本機包**。
- 收據確認的是當時來源／tree，不能單憑收據就宣稱今天的本機 archive 未損毀。失敗嘗試也應保留調查紀錄，不改寫成通過。
- `source.zip` 可能為符號連結；盤點同時計算目標是否存在。入口邏輯大小會重複計入目標，不當成可釋放磁碟量。
