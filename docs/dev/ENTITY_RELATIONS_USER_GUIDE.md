# 人物卡片與共享資料

輸出頁開啟「人物ROOT卡片／共享公司與聯絡資料」。每個人物可新增多筆聯絡欄位、建立公司或連結既有公司；公司可多人共用，一人可連結多家公司。

- 相同姓名或電話不會合併身份。共享標記列真實引用，編輯會先列所有受影響對象及舊／新值。私人欄位直接編輯，可復原／重做。
- 複製人物時選共享公司或獨立公司；私人欄位一律獨立。聯絡欄位也可另複製，字串中的分號不會拆成新欄位。
- 解除關聯只移除這個引用；仍有人引用的公司不能刪除。無引用的公司會保留在卡片底部，可核對後刪除；Logo資產原檔不隨之刪除。
- 卡片內的修改在「採用」後才成為當次輸入，取消不更動主視窗。下方舊表格改為唯讀摘要；編輯後候選過期，必須重新排版。新增欄位沒有框位時會阻擋輸出，不會藏掉資料或改定案字級。

客戶入口可人工將完整人物／公司關聯保存到同一本機資料庫。從客戶選exact版型預填後，卡片修改仍只屬本次；重新開客戶頁可逐欄看快照、當次值、目前主檔與共享影響，預設不勾選。回寫需確認與全交易CAS，過期會阻擋。歷史恢復也會產生新版本，不會自動加入過期電話搜尋別名。

舊資料可自動遷移明確歸屬並保留欄位ID；歧義資料不猜測，保留原值待核對。本包未宣稱自動AI客戶建檔、完整多尺寸縮圖、全部新增刪除回寫或個資生產權限已完成。僅用匿名資料驗收，資料庫與原稿不發布。

設計採關聯正規化與圖引用、SQLite交易／外鍵、Qt command/Undo模式，及商用CRM的明確共享影響與逐欄同步。演算法按stableID與實際邊計算引用，線性掃描不靠字串相似度判定身分；上限20人物／20公司／1000欄位，超限拒絕且不截斷。無新增外部程式或素材授權。
