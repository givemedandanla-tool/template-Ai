# 跨作品規則學習與模板生成實作方案

狀態：設計中，8個新學習工作包均未實作。使用者產品定義已確認，工程選型／數字為待實測設計建議。CURRENT008的1549項既有流程測試不等於此目標驗收。

產品目標：匯入多份作品 -> 分析可學習觀察 -> 歸納共用設計家族與參數化規則 -> 接受新輸入 -> 選擇合適家族／合成新模板 -> 約束求解與評分 -> 可驗證排版結果。禁止將每份作品複製為一份模板當作完成學習。

初步架構：現有Inkscape／fontTools／Qt解析量測、來源hash、SQLite TrainingStore、持久工作佇列、版本歷史及輸出Gate保留；新增DesignObservation、DesignFamily、RuleModel、GenerationSpec、RankingModel與EvaluationRun等版本化記錄，沿用既有資料庫／審計，避免另造平行系統。

候選工程路線：HDBSCAN找跨作品家族；正規化幾何／群組圖、median/MAD及穩健關係擬合學規則；參數化群組文法實例化新欄位組合；既有Cassowary/Kiwi解連續幾何，有限拓撲候選搜尋；CatBoostRanker從真實偏好學候選排序。商用參照Figma Auto Layout公開屬性，研究LayoutDM條件式生成；具體重用／授權／參數與驗收正在補齊。

工作包依序：AI-LEARN-01作品觀察；02跨作品家族；03共用與可變規則；04模板合成／求解；05檢索／排序；06回饋／啟用；07端到端介面與接續；08真實資料泛化／規模驗證。下一步先完成本方案的資料schema、參數表、訓練／資料切分與驗收契約，再實作01至04的垂直流程。

首個不可替代驗收：多份獨立同類作品學出一個共用家族；輸入未見過的文案／欄位組合／適用尺寸後，產出庫內不存在的新實例，保留來源與規則證據；不能靠挑一份原作品、改字與複製座標通過。真實資料與匿名合成機制測試分開計數。
