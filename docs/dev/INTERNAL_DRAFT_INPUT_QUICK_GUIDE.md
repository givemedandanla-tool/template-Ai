# 現有本體：填資料、調位置與輸出

這是目前正式本體的操作入口；現代面板概念稿另見GUI_PANEL_DESIGN_PLAN_20261020.md。

1. 開啟本體，進入「③ 排版與輸出」。可沿用表格、人物／公司與共用聯絡資料、舊客戶預填及Logo選擇。
2. 使用已啟用的學習規則時，從「預覽／拖動調整」或「共用AI規則／當次稿件」進入當次稿件。
   按「使用主視窗已填資料」可接續目前資料；「填資料／改內容」可局部更正。
   沒有啟用模型時先在學習管理完成所需步驟，不能把新學習稿與固定舊模板混為同一路徑。
3. 核對尺寸，按「產生完整稿件」。處理中可按「停止這次排版」，輸入仍保留。
4. 在預覽拖動可調整的聯絡欄位，或選擇兩欄及「在左側／右側／上方／下方」，按「調整兩欄相對位置」。
   規則會處理需要的文字與欄位適配，不提供任意調字級／字寬。可「復原位置調整／重做位置調整」。
5. 改內容後重新產稿、檢查，再按「確認目前完整預覽稿」。
   「輸出已確認預覽稿」支援PNG／PDF／JPG預覽；預覽不是正式印刷合格證明。
   正式數位輸出另須「核對當次實例並確認正式稿」與現有全部資格檢查通過。
6. 「儲存本次檢查報告」含白話摘要及技術詳情；可提供維護人員分析，不需上傳私人作品、字型或資料庫。
   重訂時可查找原先確認的稿件，按「開啟已保存的相同檔案」核對沿用。

注意：選擇已發布固定款式／舊客戶固定版本時，仍沿用該版本；明確切換路徑後才使用學習稿。
已確認稿不會因啟用新模型而默默換稿。固定模板多尺寸批次仍在原工作區，學習稿按實際尺寸個別核對。
