# Template AI v0.1.1 第一版操作說明

這是「矩形區域自動排版與模板 AI」的第一個可操作研究版。使用者於 2026-10-12 明確指示「開始照計畫製作第一版軟體」，本輪已進入程式開發。請以合成或合法匿名資料測試；完整個資權限仍依既有決策留在後期。

## 安裝與開啟

### Windows 成品

若 GitHub Windows 工作流程成功產生附件，下載 `TemplateAI-v0.1-Windows.zip`，完整解壓縮後執行資料夾內的 `TemplateAI-v0.1.exe`。保留 `_internal` 與其他同層檔案，不能只搬走 EXE。打包為可分離動態 Qt 函式庫的資料夾版。

`.ai`／EPS／SVG 的 Inkscape 解套路徑需另外安裝 Inkscape 1.4 或更新的相容版本；本版查找 PATH 和 Windows 標準安裝位置。可選擇以 `TEMPLATE_AI_INKSCAPE` 指定執行檔。Inkscape 不隨 EXE 重發。未安裝時，PDF 相容內容可走 Qt PDF，SVG 可走 Qt SVG；不支援的來源明示失敗，不會假裝解析完成。

### 原始碼啟動

安裝 Python 3.11 後，Windows 雙擊 `START_WINDOWS.bat`。它在專案資料夾建立 `.venv` 並安裝鎖定依賴，失敗時保留訊息。其他系統：

```bash
python -m venv .venv
# Windows：.venv\Scripts\python；Linux：.venv/bin/python
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python app.py
```

安裝與執行不需要 GitHub token；應用程式不會自行把圖稿或資料送到網路。

## 先跑匿名示範

1. 進入「② 模板與 Logo」，按「加入合成示範模板」。
2. 按「驗證並發布」，確認規則。這只是示範模板，不冒稱由歷史 Illustrator 訓練得來。
3. 進入「③ 排版與輸出」，按「填入匿名示範資料」，矩形尺寸保持 90×54 mm。
4. 按「開始自動排版」，選取通過的候選，查看結果及理由。
5. 按正式輸出，可選 PNG、PDF 或 JPG。本版的「正式」指已通過軟體數位排版檢查，未包含實體印刷驗收。

## 從自己的來源學習模板

1. 「① 訓練與原稿標記」選取 AI／PDF／SVG／PNG／JPG。多頁 PDF／PDF 相容 AI 在匯入前設定頁碼；每頁是獨立來源登錄。
2. 與可信原稿核對。可載入參考圖量測像素差異；不同像素尺寸不會自動拉伸並宣稱一致。務必核對原稿中的文字、圖形、Logo、相對位置與細節。
3. 一份來源有多個作品時，按「框選作品」，在原圖框出一件矩形作品，輸入該作品寬高毫米。點陣來源的顯示毫米不是原稿真值，需要此步標定。
4. 選右側欄位類型，再按「新增欄位框」於作品中拖出矩形。歸屬選單可選人物 1、公司 1 等；同類資料多筆以序號區別。公司 Logo 必須框住完整文字＋圖形。
5. 選「選取／移動」或從欄位清單選取，右側可編輯毫米位置、大小、字型、已定案字級、文字色彩（#RRGGBB）、對齊及此模板的字寬下限；按「套用至選取欄位」才提交輸入值。
6. 勾選「已與可信原稿對照，確認此作品視覺一致」。本版不自動將高相似度分數變成人工核准。
7. 保存標記，按「依標記學習模板」。有公司欄位時逐人物確認公司歸屬；模板先進草稿，經驗證與人工確認後發布。
8. 若要學另一作品，先完成現有作品的模板，再重新框選；切換作品會清空當前標記，已保存的模板保留。

本版「學習」是將已確認的框位、歸屬、字級、字寬界限、對齊與來源內化為可重用規則模板。沒有自動神經模型訓練或全自動欄位辨識；原始字型／字級未知時，本模板設計值不冒稱原稿原生屬性。

## 保留原稿裝飾與背景

1. 用 Inkscape 或原設計工具另存一份原稿複本，清除姓名、聯絡資訊等可變資料，以及要由 Logo 欄位替換的圖文；只保留固定裝飾。請勿修改原始來源。
2. 將乾淨背景的頁面設為與模板相同的毫米尺寸。背景只支援完整同尺寸頁面；不自動拉伸、裁掉圖案或以白色覆蓋未知文字。SVG 外連圖片需先內嵌。
3. 在「② 模板與 Logo」選取草稿，按「匯入乾淨固定背景」。PDF 相容來源目前使用背景檔第 1 頁；請先另存目標頁。已發布模板需先建立新版本草稿。
4. 核對左側匯入參考和右側實際呈現。可選保留向量，或使用匯入圖像保留視覺；不同渲染器的 SVG 效果可能有差異。圖像模式以來源預覽圖片作背景，不會增加細節或保證印刷解析度。
5. 確認沒有舊人物資料，且圖案色彩符合原稿後核准背景；它會保存在草稿。模板畫布、排版預覽與 PDF／PNG／JPG 使用同一套背景呈現。
6. 背景內容變更或檔案失聯會阻擋發布／輸出，需重新匯入並核准；移除背景只改目前草稿，不改歷史發布版本。

`examples/synthetic-background.svg` 是 90×54 mm 合成背景，可搭配匿名示範模板試用。沒有核准背景的模板仍使用空白背景；原稿裝飾不會自動從有舊資料的來源中分離。文字色彩由人工指定，未冒稱自動讀出原稿原生色彩。

## Logo 與公司

- 在訓練原稿選取「完整 Logo」框，可在視覺核對後「核准為 Logo」；SVG 來源使用保留的 SVG 和裁切區域繪製，PDF 適用時保留向量。
- 可另外匯入完整 Logo；核准時對應的是輸出工作區目前的矩形尺寸與確認公司名稱。
- 輸出資料中填公司序號，例如人物公司序號 1 對應下方公司第 1 列；手動選該公司同尺寸已核准 Logo，名稱和尺寸不符會阻擋。
- 缺少必要真實 Logo 時，畫面使用黑底白字占位，只能另存名稱含 PREVIEW 且內容有非正式附註的預覽檔。
- 本版每人物支援一個明確公司關聯；多人物可共用公司，多家公司可由不同人物分別關聯。一人物多家公司、公司實體的完整身份審核留後續版本。

## 保存、版本、復原與檔案保護

SQLite、來源快取、Logo 在使用者的本機應用程式資料目錄保存；可用 `python app.py --data-dir 路徑` 指定隔離測試目錄。來源檔只讀；異名同內容共享解析快取，原始路徑登錄保留獨立識別。

標記按保存或正常關閉／來源切換時保存。模板草稿保存至本機，已發布版本唯讀；需要修改時「建立新版本草稿」。畫布標記／草稿有目前模式的復原、重做；切換模式會清除該模式的暫態 Undo 佇列，但已保存內容不被改寫。未按套用的右側輸入尚未提交，請先套用再切換選取。

改人物資料、尺寸、模板或 Logo 後，舊候選過期，需重新排版。輸出前再核對版本；不覆寫既有檔案。檔案先完整寫至同資料夾暫存，才以排他硬連結發布；不支援硬連結的目的磁碟會失敗，請改存支援的本機磁碟，不能假稱成功。

## 第一版支援範圍

已實作：三模式 GUI、來源匯入／同內容快取、多頁選頁及頁碼檢查、匯入前像素預算檢查、手動作品與欄位框、視覺確認、規則模板學習、模板草稿／發布／新版本、毫米編輯、固定字級度量與文字色彩、人物公司歸屬、同尺寸 Logo、人工核准乾淨背景、候選配對／排序、過期判定、PDF／PNG／JPG 與獨立 PREVIEW、安全保存、程式內字型載入。

後續版本：全自動多作品切分／語意辨識、深度模型與大規模樣本庫、模板聚類歸納／少樣本新尺寸預測、無模板特製排版、候選人工修改與跨尺寸同步、客戶主檔／重訂、完整加密備份移轉／失聯來源重連、持久字型資產、完整權限／個資安全、實體印刷分析。

技術支持範圍：單檔來源 200 MB；來源預覽 1200 萬像素；點陣輸出 2400 萬像素；單工作尺寸最大 2000 mm；本版人物／公司列最多 20。這些是可診斷的本版資源防護設定，非實測的最低硬體或通用印刷標準。DPI 72～600 是數位編碼設定。

實機效能仍按 16 GB 系統 RAM＋RTX 5050 與待補型號 ASUS VivoBook 後續量測；本版不需要 CUDA，核心走 CPU。
